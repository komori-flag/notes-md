# 变量

[//]: # (py: demo)
```python
# 张三
18
print("张三的年龄是", 24)
print('张三的年龄是：', 24)
print('张三的年龄从', 24, '提升')
```

我们用 print 函数打印了三次 24，一旦 24 发生了变化，我们就需要修改用到值 24 的地方，这显然麻烦，所以此处需要引入一个新的概念，即**变量**。

在 Python 中，变量的本质就是一个**代号**，其作用是用于与某个值（到02课为止只有字面量，以后还有更多）建立**绑定关系**。

当我们需要*读取*或*修改*某个值时，我们只需要通过**变量**名来访问或修改即可。

变量可以**随时改变**。

## 变量的语法

**<font style="color:red">变量名</font> = <font style="color:red">值</font>**

??? note "例子"
    [//]: # (py: variable)
    ```python
    # 张三
    name = '张三'
    # 18
    age = 18
    # 24
    score = 24
    ```


在数学书当中，<font style="color:green">数字1 + 数字2 = 数字1+2结果</font> 为等式，`数字1 + 数字2` 是具体的运算，`数字1+2结果` 为结果。

但在编程当中，`变量名 = 值` 不是等式，其为**<font style="color:red">赋值语句</font>**，将 `值` 绑定到 `变量名` 上，`变量名` 为变量，`值` 为值。

**在 python 当中**，当一个**新的变量**出现时，必须**立即**与某个值**绑定**，否则会报错。

??? note "例子"
    [//]: # (py: undefined)
