# 数据类型概述

Python 中常见的基本数据类型包括 **整型（int）**、**浮点型（float）** 和 **字符串（str）**。可以使用 `type()` 函数查看数据的类型。

```python
import sys

# 数据类型

# int 整型
int_type_result = type(123)
print(int_type_result)  # <class 'int'>
# 整型为没有小数点的数字，可为正数也可为负数也可为0
print(type(123))  # <class 'int'>
print(type(-123))  # <class 'int'>
print(type(0))  # <class 'int'>
# 当整数的值很大的时候，可以使用下划线将数字分组表示，使其更易读
# 以下约定每三个数字为一组，每组用下划线分隔
print(3000000)  # 3000000
print(3_000_000)  # 3000000
print(1_000_000_000)  # 1000000000
print(12_000_000)  # 12000000
# 扩展内容
# Python 中整数的上限值，取决于执行环境的内存大小，通常为 2^31 - 1，即 2,147,483,647。
# a = 9999999999999999999999999999999999999999999999
# a = 9 ** 9999 # 指数运算，9的9999次方
# # print(a) # int -> str 过程限制 4300 位，此处报错 ValueError: Exceeds the limit (4300 digits)
# b = a + 100 # 此处证明了此系统可以表达9的9999次方
# sys.set_int_max_str_digits(0) # 取消上限限制
# print(a) # 

# str
print(type('张三'))  # <class'str'>
name = "张三"
print(type(name))  # <class'str'>，变量 name 所存放的数据类型是 str


# float
print(type(3.14))  # <class 'float'>
```
