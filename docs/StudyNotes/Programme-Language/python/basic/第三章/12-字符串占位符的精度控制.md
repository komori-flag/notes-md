# 字符串占位符的精度控制

字符串占位符可以通过 `%{m}.{n}s` 的形式对输出进行限制：

- **m** — 展示的总位数，不足补空格（正数右对齐，负数左对齐）
- **n** — 最多输出 n 个字符，超出则截断

```python
# 字符串占位符的精度控制
# 以这几个占位符举例子： %s（字符串）、%d（十进制整数）、%f（浮点数）

# 可以通过：%{m}.{n}s 的形式对展示的数据进行一些限制
# m 表示展示的总位数，位数不够会自动使用空格进行补全，但小于m的位数不会被截断；正数为右对齐，负数为左对齐；
# n 表示精度，最多输出n个字符（如果n大于实际字符串长度，则输出全部）

print("字符串：%s。" % "Hello") # 字符串：Hello。
print("字符串：%8s。" % "Hello") # 字符串：   Hello。（右对齐，左边用空格填充）
print("字符串：%-8s。" % "Hello") # 字符串：Hello   。（左对齐，右边用空格填充）

print("字符串：%2.2s。" % "Hello") # 字符串：He。（截断，只展示前两个字符）
print("字符串：%2.4s。" % "Hello") # 字符串：Hell。（截断，只展示前四个字符）
print("字符串：%2.8s。" % "Hello") # 字符串：Hello。（全部展示，且不补位）
print("字符串：%2.0s。" % "Hello") # 字符串：  。（不展示任何字符）
```
