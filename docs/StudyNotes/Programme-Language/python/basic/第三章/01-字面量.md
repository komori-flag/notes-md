# 字面量

## 什么是字面量？

先以一个简单的例子来说明字面量：

```text
老师让学生将自己的姓名、年龄写在纸上：

张三 20 
李四 25 
王五 30 

纸上的文字，是学生直接表达的内容，不需要通过计算和转换来获得，表示字面上的含义。
```

**字面量**是指在编程语言中**直接表示数据**的值，而不是通过变量来引用。字面量可以是常量、变量、表达式等。

[//]: # (py: errors)
```python
张三 # 错误
20 # 警告


李四 # 错误
25 # 警告


王五 # 错误
30 # 警告
```

### 1. 字符串

直接填写字面量的话会看到错误及警告，在执行时会看到具体的错误信息。

```log
Traceback (most recent call last):
  File "第三章\01-字面量.py", line 2, in <module>
    张三 # 错误
    ^^^^
NameError: name '张三' is not defined
```


如何解决呢？将名字通过双引号或单引号括起来，这样Python会将名字看作*字符串，而不是变量。

#### 什么是字符串？
由字母、数字、符号等组合而成的字符串，可以用来表示文本信息。python 字串需要用**双**引号、**单**引号、**三个单**引号或**三个双**引号括起来，例如：
[//]: # (py: string)
```python
"张三" # 正确
'李四' # 正确
"王五" # 正确
'张三' # 正确
```
实际开发当中使用单引号较为普遍，其写起来更简单。
[//]: # (py: single)
```python
'张三' # 正确
'李四' # 正确
```
字符串不仅可以包含字母、数字、符号，也可以是其它语言、表情符号或者是它的组合。例如：
[//]: # (py: multilang)
```python
'你好，世界！' # 正确
'hello 时间' # 正确
```

### 2. 数字

解决了字符串问题后，又发现了数字部分的警告信息，提示语句似乎不起作用。

这个为内置 pycharm 提供的警告信息，不推荐进行关闭。

### 3. 文档字符串

在 Python 中，文档字符串（docstring）是一种特殊的字符串，用于**描述**当前 py 文件的功能，**必须使用三引号**（`'''` 或 `"""`）括起来。

[//]: # (py: docstring-double)
```python
"""这是一个文档字符串，用于描述当前 py 文件的功能。"""
```

[//]: # (py: docstring-single)
```python
'''这是一个文档字符串，用于描述当前 py 文件的功能。'''
```
