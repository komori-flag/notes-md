# 标识符

## 什么是标识符？

程序当中所有我们可以**自己起名**的内容（截至03课只有变量名，还有函数、类、模块名等），我们称之为标识符。

??? note "例如"
    ```python
    # name、age、weight都是标识符
    name = 张三'
    age = 20
    weight = 70
    ```


## 标识符的命名规则

1. 只能包含：*字母、数字、下划线（`_`）*，不能**以数字开头**，不能包含**空格**。
2. 编程语言当中的标识符是**<font color="red">区分大小写</font>**的，例如：`name`和`Name`是两个不同的标识符。
3. 标识符**<font color="red">不能是关键字</font>**，例如：`if`、`else`、`for`、`while`等。
4. 标识符**<font color="red">尽量不要</font>**与内置函数同名，例如：`print`、`input`、`range`等。
5. 标识符没有长度限制，但建议：**<font color="green">简洁清晰，具有描述性</font>**，命名写法 Python 推荐使用**蛇形命名法**（所有单词用下划线连接），例如：`user_name`、`user_name_top`、`user_name_last`等。

??? note "例子"
    ```python
    # 能包含：字母、数字、下划线（_）
    name2 = "Tom"
    age_2 = 20
    _weight_ = 70

    # 不能以数字开头
    3name = "Tom"  # 错误

    # 不能包含空格
    name 3 = "Tom"  # 错误

    # 不能包含特殊字符
    _name@name2_ = "Tom"  # 错误
    _name-name2_ = "Tom"  # 错误
    _name!name2_ = "Tom"  # 错误
    _name%name2_ = "Tom"  # 错误

    # 区分大小写
    Name = "Tom1"
    name = "Tom2"
    print(Name)  # Tom1
    print(name)  # Tom2

    # 不能是关键字
    as = "Tom"  # 错误
    if = "Tom"  # 错误
    for = "Tom"  # 错误

    # 尽量不要与内置函数同名
    print = "Tom"  # 不会发生错误，但覆盖了内置函数
    print("Tom")  # 错误：print不是一个可执行的函数


    # 简洁清晰，具有描述性
    userName = "Tom" # 小驼峰命名法（首字母小写，后续单词首字母大写）
    UserName = "Tom" # 大驼峰命名法（所有单词首字母小写）
    user_name = "Tom" # 蛇形命名法（所有单词用下划线连接，Python推荐使用）
    ```
