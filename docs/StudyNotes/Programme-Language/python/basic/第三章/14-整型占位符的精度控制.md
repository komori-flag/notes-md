# 整型占位符的精度控制

整型占位符通过 `%{m}.{n}d` 的形式控制输出格式：

- **m** — 展示的总位数，不足补空格（正数右对齐，负数左对齐）
- **n** — 精度控制，位数不够用 `0` 补位，小于整数位则自动失效

```python
# 整型占位符的精度控制

# 其与字符串或浮点型的类似，也有精度控制的功能。
# m 表示展示的总位数，位数不够会自动使用空格进行补全，但小于m的位数不会被截断；正数为右对齐，负数为左对齐；
# n 表示精度控制，位数不够用0来补，位数小于整数位则自动失效

# 示例：
print("%.4d。" % 12) # 0012。
print("%.1d。" % 12) # 12。
```
