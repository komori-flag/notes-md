# 嵌套分支

课程来源：尚硅谷 Python 零基础教程（P34）
核心主题：Python 条件判断中的嵌套分支（Nested if）

## 什么是嵌套分支？

在一个 `if` / `if-else` / `if-elif-else` 语句的代码块内部，再完整地放入另一个分支结构，就称为嵌套分支。

* 外层分支：外层的 if
* 内层分支：嵌套在里面的 if

**本质**：实现更复杂、多层级的条件判断逻辑。

## 语法形式

1. if 中嵌套 if-else
```python
if 条件1:
    if 条件2:
        # 条件1 和 条件2 都成立时执行
        代码块1
    else:
        # 条件1 成立，条件2 不成立时执行
        代码块2
```

2. if-else 中嵌套 if-else
```python
if 条件1:
    if 条件2:
        代码块1
    else:
        代码块2
else:
    if 条件3:
        代码块3
    else:
        代码块4
```

## 示例


??? note "马拉松比赛审核程序"
    ```python
    # Python 报名审核程序 - 基于嵌套分支（P34）
    print("=== Python 报名审核系统（嵌套分支版）===")
    name = input("请输入报名者姓名：")
    age = int(input("请输入报名者年龄："))
    has_checked = input("是否已体检（Y/N）：").strip().upper() == 'Y'
    print("\n【审核结果】")
    # 外层分支：年龄
    if age >= 18:
        # 内层分支：体检
        if has_checked:
            print(f"亲爱的 {name}，您已成年且已体检！")
            print("✅ 恭喜通过报名审核，可获得 500 元奖励！")
        else:
            print(f"亲爱的 {name}，您已成年但未体检！")
            print("⚠️ 无法报名，需先完成体检")
            print("   罚款：300 元")
    else:
        # 未成年处理（仅年龄层级）
        print(f"亲爱的 {name}，您未成年！")
        print("❌ 无法报名")
        print("   免费资格已激活（无需体检）")
        print("   奖励：免费赠送 100 元学习礼包")
    print("\n【系统提示】")
    print("本程序基于 P34 嵌套分支教学设计，控制在 2 层嵌套，逻辑清晰。")
    print("建议：画流程图验证后，再输入数据测试！")
    # 扩展功能：增加第二次机会（演示 if-elif-else 优化）
    print("\n【二次审核】")
    try_again = input("是否需要二次审核？（Y/N）：").strip().upper() == 'Y'
    if try_again:
        if age >= 18 and has_checked:
            print(f"{name}，恭喜！您已通过！")
        else:
            print(f"{name}，二次审核未通过，请先完成体检。")
    ```
