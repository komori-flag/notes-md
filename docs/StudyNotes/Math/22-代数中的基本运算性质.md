上一节学会了用字母代表数。这一节回答的是下一个问题：**字母能不能像数字一样做运算？**

答案是能——算术里的那些**数的性质（number properties）**，在代数里几乎原样成立。视频把最重要的几条逐条过了一遍：[**分配律**](10-算术的分配律.md)、[**交换律**](10-算术的分配律.md#_2)、[**结合律**](10-算术的分配律.md#_2)、[**单位元性质**](#identity-property)、[**逆元性质**](#inverse-property)。

其中**分配律最重要**，因为它是这些性质里唯一能真正"改变式子的形状"的一条——展开括号、提取公因式，靠的都是它。

## 一、分配律：为什么代数比算术更需要它

回顾 [10. 算术的分配律](10-算术的分配律.md)：

$$a(b + c) = ab + ac$$

**在算术里，这条性质其实"可有可无"。** 比如：

$$4(2 + 3) = 4 \times 2 + 4 \times 3 = 8 + 12 = 20$$

但括号里的 $2 + 3$ 本来就能先算成 $5$，再乘 $4$：

$$4(2 + 3) = 4 \times 5 = 20$$

两条路都得 20，所以算术里分配不分配无所谓。

**在代数里，情况变了。** 把 $2$ 换成 $2x$：

$$4(2x + 3)$$

括号里的 $2x + 3$ **没法先算成一个数**——$2x$ 和 $3$ 是两类不同的项，加不到一起。这时还能怎么办？只剩一条路：**把 4 分配进去**。

$$4(2x + 3) = 4 \times 2x + 4 \times 3 = 8x + 12$$

!!! note "这就是分配律在代数里的意义"

    算术里分配律只是"另一种算法"；代数里它往往是**唯一能把括号去掉、把式子化简的方法**。

    视频的说法是：在代数里我们要"以这种方式使用分配律"（use the distributive property this way）——也就是**为了化简而展开**，而不是为了心算。

!!! tip "补充（视频未讲）：怎么验证等价"

    把 $x$ 随便取一个值代进去，两边结果应该相同。

    $x = 1$ 时：

    $$4(2 \times 1 + 3) = 4 \times 5 = 20$$

    $$8 \times 1 + 12 = 8 + 12 = 20$$

    两边相等。$x = 2$、$x = -3$ 也一样。**对变量的每一个取值，两个式子都给出相同结果**，它们就叫**等价表达式（equivalent expressions）**。

    分配律做的每一次变形，本质上都是在生产一个与原来等价的新表达式。这也是后面解方程合法的根基。

## 二、反向使用分配律：提取公因式

分配律不仅能从左往右用，还能**从右往左用**：

$$ab + ac = a(b + c)$$

视频给的说法是：从一个和或差里**把公因数提出来**（removing some common factor）。

### 2.1 例子：$3x^2 + 6x$

这个式子由两项组成。先把每一项拆成因数：

$$3x^2 = 3 \cdot x \cdot x$$

$$6x = 2 \cdot 3 \cdot x$$

两项**共有**的因数是 $3$ 和 $x$，乘起来：

$$\text{最大公因数} = 3x$$

（$3$ 是 $3$ 和 $6$ 的最大公因数，见 [17. 最大公因数](17-最大公因数.md)；字母部分取两次里较低的那个次幂 $x$。）

### 2.2 把 $3x$ 提出来

"提出来"的意思就是**把每一项都除以 $3x$**：

$$3x^2 \div 3x = x$$

$$6x \div 3x = 2$$

留在括号里的就是这两个商：

$$3x^2 + 6x = 3x(x + 2)$$

### 2.3 用分配律验算

把 $3x$ 重新乘回去，应该还原：

$$3x(x + 2) = 3x \cdot x + 3x \cdot 2 = 3x^2 + 6x$$

（$3x \cdot x = 3x^2$，即 $x \cdot x = x^2$，见 [14. 指数](14-指数.md)。）

也对得上。这个"提出来再乘回去"的验算，是检查因式分解有没有做对的标准动作。

!!! note "提取公因式 = 因式分解的第一步"

    把一个多项式写成几个因式的乘积，叫**因式分解（factoring）**。$3x^2 + 6x = 3x(x+2)$ 就是把一个二项式分解成了两个因式相乘。

    分配律的左右两个方向，恰好就是因式分解和展开——它们是互逆的两件事：

    展开：$3x(x+2) \longrightarrow 3x^2 + 6x$
    分解：$3x^2 + 6x \longrightarrow 3x(x+2)$

!!! warning "提取公因式时最容易漏的地方"

    - **两项都要除**：$3x^2 + 6x$ 提出 $3x$ 后，括号里是 $x + 2$；只把第一项除了、写成 $3x(x + 6x)$ 就错了。
    - **提出什么就留下什么**：如果两项的公因式全被提干净（比如 $3x^2 + 3x$ 提 $3x$），括号里会剩 $1$，不能省略成空：$3x(x+1)$，不是 $3x(x)$。

## 三、交换律（Commutative Property）

**加法、乘法交换顺序，结果不变。** 这条性质在代数里原样成立：

$$2 + 3 = 3 + 2$$

$$2 \times 3 = 3 \times 2$$

换成代数项也一样——"加或乘的顺序无关紧要"（the order in which we add or multiply algebraic terms is irrelevant）：

$$2x + 3 = 3 + 2x$$

$$2x \times 3 = 3 \times 2x$$

（后一个式子两边都可以写成 $6x$。）

!!! warning "减法和除法不满足交换律——代数里也不满足"

    $$3 - 2 \neq 2 - 3 \qquad 6 \div 2 \neq 2 \div 6$$

    这一点不会因为换成字母就改变：

    $$x - 3 \neq 3 - x \qquad x \div 3 \neq 3 \div x$$

    视频专门强调这一点，是因为很多代数错误就出在"随手交换顺序"上。

!!! tip "补充（视频未讲）：减法和除法为什么特殊"

    减法和除法都可以改写成"加上/乘以逆元"：

    $$a - b = a + (-b)$$

    $$a \div b = a \times \frac{1}{b}$$

    改写成加法和乘法以后，交换律照样成立——但**交换的已经不是原来的东西了**。$3 + (-2)$ 交换后是 $(-2) + 3$，值仍然是 $1$；而 $3 - 2$ 交换成 $2 - 3$，实质上是把"减数"和"被减数"换了位置，值当然变了。

## 四、结合律（Associative Property）

**加法、乘法改变分组方式，结果不变。** 代数里同样适用：

$$(2 + 3) + 4 = 2 + (3 + 4)$$

$$(2 \times 3) \times 4 = 2 \times (3 \times 4)$$

换成代数项：

$$(2x + 3) + 4 = 2x + (3 + 4) = 2x + 7$$

视频提到，这条性质**以后处理"项数很多的方程"时会派上大用场**——因为那时我们经常要重新分组，把同类的东西放到一起。

!!! tip "补充（视频未讲）：结合律 + 分配律 = 合并同类项"

    比如化简 $3x + 5x + 2x$：

    $$3x + 5x + 2x = (3 + 5 + 2)x = 10x$$

    第一步用的是**反向分配律**（把公共的 $x$ 提出来），中间重新分组用的是**结合律**。

    这种把"字母部分相同的项"合成一项的操作叫**合并同类项**，是后面每一节都会用到的动作。

## 五、单位元性质（Identity Property）

这两条几乎是"废话"，但视频说它们"迟早会派上用场"（it will come in handy）。

### 5.1 加法单位元：0

> 任何数或代数项加上 0（或减去 0），还是它自己。

$$5 + 0 = 5$$

$$3x - 0 = 3x$$

### 5.2 乘法单位元：1

> 任何数或代数项乘以 1，还是它自己。

$$4x \times 1 = 4x$$

!!! note "为什么叫"单位元""

    "单位元（identity element）"是指**做某种运算时不会改变对方的那个特殊数**：

    - 加法里的单位元是 $0$——加上它，值不变；
    - 乘法里的单位元是 $1$——乘上它，值不变。

    注意减法里"减 0"不变，但"0 减一个数"会变号；除法里"除以 1"不变，但"1 除以一个数"会取倒数。所以严格说，$0$ 只是**加法**的单位元，$1$ 只是**乘法**的单位元。

## 六、逆元性质（Inverse Property）

### 6.1 加法逆元：相反数

> 任何数加上它的**加法逆元**，等于 0。

$$x + (-x) = 0$$

$-x$ 就是 $x$ 的加法逆元（additive inverse），也就是**相反数**。比如 $5$ 的加法逆元是 $-5$，因为 $5 + (-5) = 0$（负数的运算见 [13. 负数](13-负数.md)）。

### 6.2 乘法逆元：倒数

> 任何数乘以它的**乘法逆元**，等于 1。

$$x \times \frac{1}{x} = 1$$

$\dfrac{1}{x}$ 就是 $x$ 的乘法逆元（multiplicative inverse），也就是**倒数**。

!!! warning "乘法逆元有前提：$x \neq 0$"

    视频写 $x \times \dfrac{1}{x} = 1$ 时默认了 $x \neq 0$。

    因为 $0$ 不能作除数，$\dfrac{1}{0}$ 没有意义——**0 没有倒数**。所以这条性质对 $x = 0$ 不成立。

    加法逆元没有这个限制：$0$ 的加法逆元就是 $0$ 自己（$0 + 0 = 0$）。

| [交换律](10-算术的分配律.md#_2) | commutative | $a+b=b+a$，$ab=ba$ | $2x+3=3+2x$ | ❌ |

## 八、这些性质为什么重要

代数里的每一步化简，背后都必须有一条性质撑着。把式子变形而不改变它的值，靠的不是"看起来像"，而是这些**被证明过的规则**：

| 你想做的事 | 用到哪条性质 |
| --- | --- |
| 去掉括号 | 分配律（正向） |
| 分解因式 | 分配律（反向）+ 最大公因数 |
| $3x$ 写成 $x \cdot 3$ | 交换律 |
| $(3x + 5x) + 2x$ 重新分组 | 结合律 |
| 去掉式子里的 $+0$、$\times 1$ | 单位元性质 |
| 把 $+(-x)$ 消成 $0$、把 $\times \dfrac{1}{x}$ 消成 $1$ | 逆元性质 |
| 合并同类项 | 反向分配律 + 结合律 |

!!! note "下一步：解方程"

    视频结尾说，数的性质"差不多就这些了，接下来进入方程"（let's get to some equations）。

    下一节开始，这些性质会从"化简表达式的工具"升级成"**解方程的依据**"——因为解方程本质上就是：**在等式两边反复使用这些性质，直到未知数单独留在一边。**

## 九、核心总结

```
                  数的性质
                     │
        ┌────────────┼─────────────┐
        │            │             │
     分配律        交换律        结合律
    a(b+c)=ab+ac  a+b=b+a       (a+b)+c=a+(b+c)
        │        ab=ba         (ab)c=a(bc)
     展开 ↔ 分解   加减、乘除都 只对加、乘
        │        不适用        有效
    化简、因式分解   重排项      重新分组
                     │
              ┌──────┴──────┐
              │             │
           单位元         逆元
         +0 不变         a+(-a)=0
         ×1 不变         a×(1/a)=1
```

| 知识点 | 说明 |
| --- | --- |
| 分配律 | 代数里最重要的性质；正向展开括号，反向提取公因式 |
| 代数里为何必须分配 | $2x+3$ 无法先合并，只能把外面的数乘进去 |
| 提取公因式 | 找出各项的最大公因数，各项分别除以它 |
| 等价表达式 | 对变量所有取值结果都相同的两个式子 |
| 交换律 | 加、乘可以换序；减、除不可以 |
| 结合律 | 加、乘可以重新分组；减、除不可以 |
| 单位元 | 加法的 0、乘法的 1 不改变原值 |
| 逆元 | 加法用相反数消成 0；乘法用倒数消成 1，且要求非零 |

> **一句话总结**：代数里的每一步变形都必须有"执照"——分配律负责展开和分解，交换律负责换序，结合律负责分组，单位元和逆元负责消去；除了减法和除法不能换序、不能随意分组，其余性质在代数里全部照常生效。
