# 分数、小数和百分比之间的转换

> 来源：[Professor Dave Explains - Converting Between Fractions, Decimals, and Percentages](https://www.youtube.com/watch?v=-Xt4UDk7Kzw)
>
> 所属系列：[Mathematics (All Of It)](https://www.youtube.com/watch?v=JbhBdOfMEPs&list=PLybg94GvOJ9FoGQeUMFZ4SWZsr30jlUYK)

## 一、基本概念

这节课讲解如何在**分数**（Fraction）、**小数**（Decimal）和**百分数**（Percentage）三种表示方式之间互相转换。它们本质上是**同一数值的不同表达形式**，掌握转换后能更灵活地用于计算和比较。

- 百分数本质是"分母为 100 的分数"。

## 二、转换方法（重点）

### 1. 百分数 → 分数

百分数本身就是"除以 100"。

- 例：$30\% = \dfrac{30}{100}$，约分后得到 $\dfrac{3}{10}$。
- 小技巧：分子和分母末尾的 0 可以直接划掉（相当于除以 10）。

### 2. 百分数 → 小数

把小数点向**左**移动两位（因为百分号相当于 $\div 100$）。

- 例：$30\% \rightarrow 0.30 \rightarrow 0.3$
- 例：$8.25\% \rightarrow 0.0825$
- 注意：如果左边位数不够，前面补 0。

### 3. 小数 → 百分数

把小数点向**右**移动两位（相当于 $\times 100$），再加百分号。

- 例：$0.84 \rightarrow 84\%$

### 4. 分数 → 百分数

先把分数转换成小数，再把小数转成百分数。

- 例：$\dfrac{3}{5} = 0.6 = 60\%$

## 三、常用对照表

| 分数 | 小数 | 百分数 |
| --- | --- | --- |
| $\dfrac{1}{2}$ | 0.5 | 50% |
| $\dfrac{1}{4}$ | 0.25 | 25% |
| $\dfrac{3}{4}$ | 0.75 | 75% |
| $\dfrac{1}{5}$ | 0.2 | 20% |
| $\dfrac{2}{5}$ | 0.4 | 40% |
| $\dfrac{3}{5}$ | 0.6 | 60% |
| $\dfrac{1}{10}$ | 0.1 | 10% |
| $\dfrac{3}{10}$ | 0.3 | 30% |

**为什么没有 $\dfrac{1}{7}$？**

$\dfrac{1}{7}$（约 14.2857%）未在课中列出对照表，因为 $\dfrac{1}{7}$ 是**无限循环小数**，无法用简洁小数精确表示。这体现了"分母为 100"的局限性——**只有当分母整除 100 时**，才能得到有限小数形式（如 $\dfrac{1}{2}$、$\dfrac{1}{4}$、$\dfrac{1}{5}$、$\dfrac{1}{10}$ 等）。以后遇到新分数时，可先转成小数再加百分号来验证。

## 四、应用示例：比较大小

题目：把 $45\%$、$\dfrac{21}{50}$、$0.43$ 按从小到大排列。

- $45\% = \dfrac{45}{100}$
- $\dfrac{21}{50} = \dfrac{42}{100}$（分子分母同乘 2）
- $0.43 = 43\% = \dfrac{43}{100}$

结果：$\dfrac{21}{50} < 0.43 < 45\%$

## 五、实用小技巧

- 约分时划掉末尾的 0
- 转换时位数不够就补 0
- 比较大小时统一转成百分数或分母相同的分数
- 当分母不是 100 的倍数时（如 $\dfrac{1}{7}$），可手动补充到对照表中，提醒自己注意循环小数
