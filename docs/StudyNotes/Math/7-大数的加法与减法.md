# 大数的加法与减法

> 来源：[Professor Dave Explains - Addition and Subtraction of Large Numbers](https://www.youtube.com/watch?v=YFyOsvnr9ig&list=PLybg94GvOJ9FoGQeUMFZ4SWZsr30jlUYK&index=9)

## 一、为什么需要处理大数字

小数字可以直接数出来（例如 2 个苹果 + 3 个苹果 = 5 个苹果），但当数量很大时（例如 1293 个苹果 + 2614 个苹果），一个一个数不现实。此时必须依靠**数学算法**（algorithm）快速计算。

## 二、位值（Place Value）回顾

每个数字的位置代表不同的价值。例如 1293：

| 位置 | 数字 | 价值 |
| --- | --- | --- |
| 千位 | 1 | 1000 |
| 百位 | 2 | 200 |
| 十位 | 9 | 90 |
| 个位 | 3 | 3 |

即：

$$1293 = 1000 + 200 + 90 + 3$$

## 三、大数字加法（Addition）

**基本规则**：竖式加法，数字必须**按位值对齐**（千位对千位、百位对百位、十位对十位、个位对个位）。

```
  1293
+ 2614
------
```

**计算步骤**（从右向左）：

**第一步：个位**

$$3 + 4 = 7$$

**第二步：十位**

$$9 + 1 = 10$$

十位只能放一个数字，不能写 10。所以：个位写 0，多出的 1 进入百位——这叫 **Carrying the one（进位）**：

```
   1
  1293
+ 2614
------
    07
```

**第三步：百位**

$$1\ (\text{进位}) + 2 + 6 = 9$$

**第四步：千位**

$$1 + 2 = 3$$

**最终结果**：

```
  1293
+ 2614
------
  3907
```

$$1293 + 2614 = 3907$$

## 四、进位（Carry）的本质

进位不是技巧，而是十进制系统的自然规律：

- 10 个十 = 1 个百：$10 \times 10 = 100$
- 当某一位超过 9 时：保留个位数字，多出的数量进入下一位。

## 五、大数字减法（Subtraction）

例：一个商贩有 473 个苹果，卖掉 286 个，剩余多少？

**规则**：竖式排列，**较大的数字放上面**。

```
  473
- 286
------
```

**计算步骤**（从右向左）：

**第一步：个位**

$3 - 6$ 无法计算 → 向十位借 1。$1$ 个十 $= 10$ 个一：

- 十位：$7 \rightarrow 6$
- 个位：$3 + 10 = 13$

$$13 - 6 = 7$$

**第二步：十位**

$6 - 8$ 仍然不够 → 向百位借。$1$ 个百 $= 10$ 个十：

- 百位：$4 \rightarrow 3$
- 十位：$6 + 10 = 16$

$$16 - 8 = 8$$

**第三步：百位**

$$3 - 2 = 1$$

**最终结果**：

```
  473
- 286
------
  187
```

$$473 - 286 = 187$$

## 六、借位（Borrowing）的本质

借位其实是把**高位单位转换成低位单位**：

$$1\ \text{百} \rightarrow 10\ \text{个十} \rightarrow 100\ \text{个一}$$

## 七、多个数字相加

不仅可以两个数字相加，也可以一列同时相加：

$$17 + 22 + 11 + 34 + 46$$

```
   17
   22
   11
   34
+ 46
-----
```

- 个位：$7 + 2 + 1 + 4 + 6 = 20$ → 个位写 0，进位 2
- 十位：$2\ (\text{进位}) + 1 + 2 + 1 + 3 + 4 = 13$ → 直接写 13

$$17 + 22 + 11 + 34 + 46 = 130$$

## 八、核心算法总结

**加法算法**

1. 数字按位对齐
2. 从个位开始计算
3. 超过 9 则进位
4. 一直计算到最高位

**减法算法**

1. 大数字放上方
2. 从个位开始计算
3. 不够减时向高位借
4. 转换单位后继续计算

## 九、关键概念表

| 概念 | 英文 | 含义 |
| --- | --- | --- |
| 位值 | Place Value | 数字所在位置决定价值 |
| 个位 | Units Place | 最右边的位置 |
| 十位 | Tens Place | 10 个个位 |
| 百位 | Hundreds Place | 10 个十 |
| 进位 | Carry | 超过当前位容量，把值转移到高位 |
| 借位 | Borrow | 从高位借单位转换到低位 |
| 算法 | Algorithm | 解决问题的一系列步骤 |

## 十、思维模型

```
十进制系统
    ↓
位置价值
    ↓
逐位计算
    ↓
进位 / 借位
    ↓
处理任意大小数字
```

## 复习清单

- 理解十进制位置价值
- 能正确排列大数字竖式
- 掌握加法进位
- 理解为什么 10 个低位 = 1 个高位
- 掌握减法借位
- 能计算多个数字同时相加

> **一句话总结**：大数字的加减法并不是新的数学，而是把小数字运算按照「位置价值」扩展，通过进位和借位处理每一位超过容量的问题。
