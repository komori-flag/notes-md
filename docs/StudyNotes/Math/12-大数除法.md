## 一、课程主题

长除法（Long Division）是一种用于计算**大数除法**的标准算法。

- 简单除法：$12 \div 3 = 4$（因为 $4 \times 3 = 12$）
- 复杂除法：$625 \div 3$ 无法直接心算，需要使用长除法。

## 二、长除法的核心思想

> 长除法就是**乘法算法的反向过程**。

- 乘法：从右往左（个位 → 十位 → 百位）逐位相乘。
- 除法：从左往右（最高位 → 下一位 → 最低位）逐位计算。

原因：除法是乘法的逆运算。

## 三、重要术语

| 英文 | 中文 | 含义 |
| --- | --- | --- |
| Dividend | 被除数 | 被分割的数字 |
| Divisor | 除数 | 用来除的数字 |
| Quotient | 商 | 除法结果 |
| Remainder | 余数 | 剩余无法继续分配的部分 |

例：$625 \div 3 = 208\ \text{R}\ 1$，其中 625 = Dividend，3 = Divisor，208 = Quotient，1 = Remainder。

## 四、长除法四步法

> **除 → 乘 → 减 → 落（Bring down）**，不断重复。

## 五、示例一：$625 \div 3$

**第一步：从最高位开始除**

$6 \div 3 = 2$，商的百位写 2。

**第二步：乘**

$2 \times 3 = 6$，写在下面。

**第三步：减**

$6 - 6 = 0$。

**第四步：落下一位**

落下 2 → $2 \div 3$，因为 $2 < 3$，商写 0。$0 \times 3 = 0$，$2 - 0 = 2$。

再落下 5 → 得到 25。$25 \div 3$，因为 $3 \times 8 = 24$，商写 8，余 $25 - 24 = 1$。

**完整过程**：

```
    208
    ___
3 ) 625
   -6
   ---
    02
   -0
   ---
     25
    -24
    ---
      1
```

$$\boxed{625 \div 3 = 208\ \text{R}\ 1}$$

## 六、示例二：$397 \div 11$（除数是两位数）

**第一步**：11 不能进入 3（$3 < 11$），商写 0。

**第二步**：落下 9 → 得到 39。$39 \div 11$，因为 $11 \times 3 = 33$，商 3，余 $39 - 33 = 6$。

**第三步**：落下 7 → 得到 67。$67 \div 11$，因为 $11 \times 6 = 66$，商 6，余 $67 - 66 = 1$。

$$\boxed{397 \div 11 = 36\ \text{R}\ 1}$$

## 七、余数如何变成小数

如果不想留下余数，可以继续计算。以 $397 \div 11$ 为例：

- 在商后加小数点，给余数 1 补 0 → 得到 10。
- $10 \div 11 = 0$ → 商增加 0。
- 继续补 0 → 得到 100。$100 \div 11 = 9$（$11 \times 9 = 99$），余 1。

**余数又回到了 1**，说明计算开始无限重复：

$$397 \div 11 = 36.090909\ldots$$

## 八、循环小数（Repeating Decimal）

**定义**：当除法过程中出现**相同的余数**，之后的小数会无限重复。

例如：

$$\frac{1}{11} = 0.090909\ldots$$

特点：

- 小数无限延伸
- 有固定循环模式

## 九、长除法本质理解

长除法实际上是在回答：**一个数字里面包含多少组除数？**

$$625 \div 3 \Rightarrow 3 \times 208 = 624，剩 625 - 624 = 1$$

$$625 \div 3 = 208 + \frac{1}{3}$$

## 十、知识总结表

| 知识点 | 说明 |
| --- | --- |
| Long Division | 大数除法算法 |
| 运算方向 | 从左到右 |
| 本质 | 乘法的逆过程 |
| 核心循环 | 除 → 乘 → 减 → 落 |
| Dividend | 被除数 |
| Divisor | 除数 |
| Quotient | 商 |
| Remainder | 余数 |
| Decimal | 小数形式 |
| Repeating Decimal | 循环小数 |

> **一句话总结**：长除法就是从最高位开始，把除法拆成一系列简单的"除、乘、减、落"步骤，直到得到商和余数；如果继续处理余数，就可以得到小数甚至循环小数。
