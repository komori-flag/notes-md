前面几节都在"给方程、解方程"。这一节反过来：**只给一段文字，方程要自己列。**

视频开门见山：代数第一次展示了数学如何以抽象的方式解决现实问题——办法就是**把文字描述翻译成代数方程**。

## 一、解题的四个动作

视频的例题都遵循同一个套路：

1. **设变量**：文字里的哪些量会变？给它们起字母名；
2. **写关系**：把每句条件翻译成式子或方程；
3. **解方程**：用前两节的办法求出字母的值；
4. **回答问题**：把求出的值放回原问题，回答它真正问的东西。

!!! note "设变量前先问两个问题"

    视频的原话是："我们知道什么？我们想知道什么？"（What do we know, and what do we want to know?）

    - **已知**的量，用来写方程；
    - **所求**的量，就是变量，也是最后要回答的东西。

    变量设错，后面全错；变量设对，方程往往水到渠成。

## 二、例 1：Sally 和 Gabby 的年龄

> Sally 比 Gabby 年龄的两倍小 3 岁。如果 Gabby 12 岁，Sally 多大？

### 2.1 设变量

- $G$ = Gabby 的年龄；
- $S$ = Sally 的年龄。

### 2.2 把句子翻译成方程

句子的核心是"**Sally 比（Gabby 的两倍）小 3 岁**"：

$$S = 2G - 3$$

视频强调：**这个方程和上面那句话说的完全是同一件事，只是把词换成了符号。**

### 2.3 求解

这题简单到不用移项，直接把 $G = 12$ 代进去求值：

$$S = 2 \times 12 - 3 = 24 - 3 = 21$$

Sally 21 岁。

!!! warning "「比……小」的顺序最容易搞反"

    $S = 2G - 3$，**不是** $S = 3 - 2G$。

    "Sally 比 X 小 3 岁"的意思是：从 X 里减去 3，得到 Sally：

    $$\text{Sally} = X - 3$$

    英文 "three years younger than twice the age of Gabby" 同理：$2G - 3$。

    可以用具体数字验一下：Gabby 12 岁，两倍是 24，Sally 比它小 3 岁，就是 21。若写成 $3 - 2 \times 12 = -21$，年龄变成负数，显然荒谬。[^1]

## 三、例 2：三兄弟的年龄

> Huey、Louie、Dewey 三兄弟的年龄是连续的三的倍数，三人年龄之和是 36。他们各多大？

### 3.1 为什么不能靠猜

简单情形下"猜一猜、试一试"当然可以。但视频指出：**问题一旦变复杂，列方程解比猜快得多，也可靠得多。** 这就是建模的价值。

### 3.2 设变量

关键是**只设一个变量**，让另外两个都用它表示。

设最小的弟弟年龄为 $x$。三人的年龄是**连续的三的倍数**，每后一个比前一个大 3：

| 兄弟 | 年龄 |
| --- | --- |
| 最小的 | $x$ |
| 中间的 | $x + 3$ |
| 最大的 | $x + 6$ |

!!! tip "补充（视频未讲）：为什么是 $x$、$x+3$、$x+6$"

    "三的倍数"就是一串 $3, 6, 9, 12, \dots$，相邻两个差 3。中间那个就是最小的加 3，最大的再加 3，得到 $+6$。

    如果是"连续整数"，就是 $x, x+1, x+2$；"连续偶数/奇数"是 $x, x+2, x+4$。规律相同：**后一项 = 前一项 + 公差**。

### 3.3 列方程

"年龄之和是 36"——sum 就是加起来：

$$x + (x + 3) + (x + 6) = 36$$

### 3.4 解方程

合并同类项：三个 $x$ 合成 $3x$，常数 $3 + 6 = 9$：

$$3x + 9 = 36$$

两边同减 9：

$$3x = 27$$

两边同除以 3：

$$x = 9$$

### 3.5 回答问题

$x$ 是最小的弟弟的年龄，所以三人的年龄是：

$$9,\quad 12,\quad 15$$

检验：$9 + 12 + 15 = 36$，且都是 3 的倍数、彼此连续 ✅

!!! warning "别只答 $x$"

    题目问"他们各多大"，所以要给出**三个人**的年龄。$x = 9$ 只是中间产物，不是最终答案。

## 四、例 3：Rover 和 Jasper 的斑点

> Rover 和 Jasper 是两只狗，每只身上都有斑点。Jasper 比 Rover 多 6 个斑点，且 Rover 斑点数的两倍加上 Jasper 斑点数的三倍等于 68。它们各有几个斑点？

### 4.1 设变量

- $R$ = Rover 的斑点数；
- $J$ = Jasper 的斑点数。

### 4.2 两条信息，两个式子

**信息一**："Jasper 比 Rover 多 6 个"：

$$J = R + 6$$

**信息二**："Rover 的两倍 + Jasper 的三倍 = 68"：

$$2R + 3J = 68$$

### 4.3 代入消元

第二个式子里同时有 $R$ 和 $J$，没法直接解。但第一个式子告诉我们：$J$ 和 $R + 6$ 是**同一个值**，所以可以把第二个式子里的 $J$ **替换**成 $R + 6$：

$$2R + 3(R + 6) = 68$$

!!! warning "代入时必须加括号"

    $3J$ 里的 $J$ 换成 $R + 6$ 后，是 $3(R + 6)$，**不是** $3R + 6$。

    因为原来乘 3 的是**整个 $J$**，而 $J = R + 6$ 是一个整体。展开时：

    $$3(R + 6) = 3R + 18$$

    漏掉括号就会得到错误答案。[^2]

### 4.4 解方程

展开：

$$2R + 3R + 18 = 68$$

合并：

$$5R + 18 = 68$$

两边同减 18：

$$5R = 50$$

两边同除以 5：

$$R = 10$$

### 4.5 求另一个量并回答

$$J = R + 6 = 10 + 6 = 16$$

**Rover 有 10 个斑点，Jasper 有 16 个。**

检验原条件[^3]：

- Jasper 比 Rover 多 6：$16 - 10 = 6$ ✅
- 两倍 Rover + 三倍 Jasper：$2 \times 10 + 3 \times 16 = 20 + 48 = 68$ ✅

## 五、翻译词典（补充）

应用题的核心难点是"文字 → 符号"。下面这些对应关系值得记住：

| 文字 | 符号 | 注意 |
| --- | --- | --- |
| is / equals / 等于 | $=$ | — |
| sum / total / 和 | $+$ | 把各项加起来 |
| more than / 多 | $+$ | "A 比 B 多 6" → $A = B + 6$ |
| less than / 少 / 小 | $-$ | **顺序相反**："A 比 B 少 3" → $A = B - 3$ |
| twice / double / 两倍 | $\times 2$ | — |
| three times / 三倍 | $\times 3$ | — |
| product / 乘积 | $\times$ | — |
| quotient / 商 | $\div$ | — |
| per / each / 每 | $\times$（单价 × 数量） | — |
| consecutive integers | $x, x+1, x+2$ | 连续整数 |
| consecutive even/odd | $x, x+2, x+4$ | 连续偶/奇数 |
| consecutive multiples of 3 | $x, x+3, x+6$ | 连续的三的倍数 |

!!! tip "补充（视频未讲）：把句子拆成"谁和谁相等""

    几乎每个应用题条件都能写成"**甲 = 乙**"的形状：

    - "Sally 比 Gabby 的两倍小 3" → $S = 2G - 3$
    - "Jasper 比 Rover 多 6" → $J = R + 6$
    - "年龄之和是 36" → $x + (x+3) + (x+6) = 36$

    先找出句子里"被描述的那个量"，再把描述它的话整个翻成另一边的表达式，顺序就不容易错。

## 六、常见陷阱

| 陷阱 | 后果 | 对策 |
| --- | --- | --- |
| "比……少/小"把顺序写反 | 答案符号错误 | 用具体数字试用一句话验证 |
| 代入时漏括号 | 展开少乘一项 | 整体替换，先加括号再分配 |
| 只设一个变量却给另一个也设了字母 | 方程里多出未知数，解不出 | 把其余量都用同一个 $x$ 表示 |
| 只回答 $x$ | 没回答题目问的东西 | 解完再对照问题读一遍 |
| 不检验 | 错误被带进答案 | 用**原始文字条件**逐条验算 |
| 设变量没写单位/含义 | 后面自己也忘了 $x$ 是什么 | 写"设 $x$ 为……（单位）" |

## 七、检查理解（视频结尾练习）

视频最后进入"检查理解"（Checking Comprehension）环节，这里把其中的弹珠题完整做一遍。

> **原题**：There are 70 marbles, all either black or red. The number of red marbles is five less than twice the number of black marbles. How many of each color are there?
>
> **译**：有 70 颗弹珠，全部要么是黑色、要么是红色。红色弹珠的数量比黑色弹珠数量的两倍少 5 颗。每种颜色各有多少颗？

### 7.1 设变量

- $b$ = 黑色弹珠的数量；
- $r$ = 红色弹珠的数量。

### 7.2 逐句翻译

**句子一**："all either black or red" 是**隐藏条件**——没有第三种颜色，所以总数就是两种颜色之和：

$$b + r = 70$$

**句子二**："red is five less than twice black"：

$$r = 2b - 5$$

!!! warning "又见「少」的顺序陷阱"

    "five less than twice the number of black marbles" 和例 1 的 "three years younger than twice the age of Gabby" 完全同型：从**两倍里减去 5**，即 $2b - 5$，**不是** $5 - 2b$。

    代数字验一下：黑 10 颗时，红应为 $2 \times 10 - 5 = 15$；若写成 $5 - 2 \times 10 = -15$，弹珠数量成了负数，显然荒谬。

### 7.3 代入求解

第二个式子已经把 $r$ 表示成含 $b$ 的表达式，直接代入第一个式子（和例 3 的代入消元是同一招）：

$$b + (2b - 5) = 70$$

合并同类项：

$$3b - 5 = 70$$

两边同加 5：

$$3b = 75$$

两边同除以 3：

$$b = 25$$

再求红色：

$$r = 2b - 5 = 2 \times 25 - 5 = 45$$

### 7.4 用原始文字条件检验

- 总数：$25 + 45 = 70$ ✅
- 红比黑的两倍少 5：$2 \times 25 - 5 = 45$ ✅

**答：黑色弹珠 25 颗，红色弹珠 45 颗。**

!!! tip "补充：设两个变量也可以"

    本题同样可以按例 3 设两个变量、列两个方程：

    $$b + r = 70, \qquad r = 2b - 5$$

    但既然第二个式子已经把 $r$ 表示出来了，直接代入就化成一个只含 $b$ 的方程，比"两个变量 → 消元"少一步。

## 八、核心总结

```
        一段文字
           │
     ① 设变量（明确含义与单位）
           │
     ② 逐句翻译成式子 / 方程
           │
     ③ 解方程（前两节的方法）
           │
     ④ 用原始条件检验
           │
     ⑤ 回答题目真正问的问题
```

| 知识点 | 说明 |
| --- | --- |
| 设变量 | 设在"要求的量"上；其余量用它表示 |
| 翻译 | "是/等于"→$=$；"多"→$+$；"少"→$-$（顺序相反） |
| 连续量 | 连续三的倍数：$x, x+3, x+6$ |
| 代入 | 用等价的表达式替换变量，必须加括号 |
| 检验 | 代回原始的文字条件，而不只是算一遍 |
| 难点 | 难在"列"方程；一旦列好，解方程是常规操作 |

> **一句话总结**：应用题 = 翻译题——先设好变量，把每句话逐字翻成等式，剩下的就是前面已经练熟的解方程。

## 注释

[^1]: **"A 比 B 少 $n$"为什么是 $A = B - n$？** 因为少的那个是 A：从 B 出发减去 $n$，才得到 A。英文 "A is $n$ less than B" 结构相同。

    一个防错办法：把具体数字代进去读一遍。"Sally 比 Gabby 的两倍小 3 岁"：Gabby 12 岁 → 两倍 24 → 比 24 小 3 → 21。哪个式子能算出 21，哪个就写对了。

[^2]: **为什么代入一定要加括号？** 设 $J = R + 6$，则 $3J$ 表示 $3 \times J$。把 $J$ 整体换成 $R+6$：

    $$3J = 3 \times (R + 6)$$

    这是"3 乘一个和"，按分配律等于 $3R + 18$。如果写成 $3R + 6$，等于只把 3 乘到了 $R$ 上，$J$ 原本那个"6"没有乘 3——两式并不相等。

[^3]: **为什么检验要用原始文字条件？** 解方程只能保证"求出的值满足你列出的方程"。如果你列方程时翻译错了，解方程算得再对，答案仍然是错的。用原始文字逐条验算（如"Jasper 是否比 Rover 多 6""两倍加三倍是否等于 68"）能同时检查**列式**和**计算**两个环节。
