前两节都在**化简表达式**：$3x + 2$ 就是 $3x + 2$，没有"答案"可求，只能代入求值。

这一节第一次出现**等号**，问题变成：**方程里的 $x$ 到底等于几？** 也就是**解方程（solving an equation）**。

## 一、方程在说什么

看最简单的方程：

$$x + 2 = 5$$

这句话的意思是：**存在某个数 $x$，给它加上 2，结果等于 5。**

凭常识就能猜出 $x = 3$，因为 $3 + 2 = 5$。但视频指出，这种"猜"的办法对付不了更难的方程，所以要学一套**系统的解法**。

!!! note "几个必须分清的词"

    | 词 | 含义 |
    | --- | --- |
    | 方程（equation） | 含等号、含未知数的等式，如 $x + 2 = 5$ |
    | 未知数（unknown） | 方程里等待被求出的字母，如 $x$ |
    | 解（solution） | 使方程成立的未知数的值，如 $x = 3$ |
    | 解方程（solve） | 求出**所有**解的过程 |

    "方程的解"是一个**数**，"解方程"是一个**动作**——中文里这两个词只差一个字，别混。另外，一次方程通常只有一个解，但其他方程不一定[^2]。

## 二、核心原理：两边同时做同样的事

解方程的全部依据只有一句话：

> **只要对等式的两边做完全相同的事，等式仍然成立。**

视频的说法是：如果两边原本相等，我们对两边做同样的操作，两边就仍然相等。

用天平来想：左右托盘原本平衡，两边同时拿走同样重的东西、或同时加上同样的砝码，天平依然平衡。

这就是 [22. 代数中的基本运算性质](22-代数中的基本运算性质.md) 里那些性质在等式上的直接应用：两边同加一个数、同减一个数、同乘一个非零数、同除以一个非零数，等式都不被破坏。[^1]

## 三、逆运算：把操作"撤销"掉

解方程的策略分两步：

1. **看未知数正在参与什么运算**；
2. **用逆运算把它撤销**（undo each operation）。

四则运算的逆运算成对出现：

| 作用在 $x$ 上的运算 | 逆运算 |
| --- | --- |
| 加（$x + a$） | 减（两边同减 $a$） |
| 减（$x - a$） | 加（两边同加 $a$） |
| 乘（$ax$） | 除（两边同除以 $a$） |
| 除（$\dfrac{x}{a}$） | 乘（两边同乘 $a$） |

下面把视频里的五个例子逐个走一遍。

### 3.1 加 → 减

$$x + 2 = 5$$

$x$ 正在被加 2，所以两边同减 2：

$$x + 2 - 2 = 5 - 2$$

$$x = 3$$

左边 $+2$ 和 $-2$ 抵消，只剩 $x$，正是我们想要的。

### 3.2 减 → 加

$$N - 4 = 17$$

$N$ 正在被减 4，所以两边同加 4：

$$N - 4 + 4 = 17 + 4$$

$$N = 21$$

### 3.3 乘 → 除

$$4D = 20$$

$D$ 正在被乘 4，所以两边同除以 4：

$$\frac{4D}{4} = \frac{20}{4}$$

$$D = 5$$

左边 4 和 4 约掉，用的是 [19. 分数的乘法与除法](19-分数的乘法与除法.md) 里"分子分母同除一个数，分数值不变"的道理。

### 3.4 除 → 乘

$$\frac{Y}{8} = 3$$

$Y$ 正在被除以 8，所以两边同乘 8：

$$\frac{Y}{8} \times 8 = 3 \times 8$$

$$Y = 24$$

### 3.5 小结：每个例子的对照

| 方程 | $x$ 参与的运算 | 撤销方法 | 解 |
| --- | --- | --- | --- |
| $x + 2 = 5$ | 加 2 | 两边减 2 | $x = 3$ |
| $N - 4 = 17$ | 减 4 | 两边加 4 | $N = 21$ |
| $4D = 20$ | 乘 4 | 两边除以 4 | $D = 5$ |
| $\dfrac{Y}{8} = 3$ | 除以 8 | 两边乘 8 | $Y = 24$ |

## 四、需要两步的例子：$4 - B = 7$

这个例子长得有点迷惑，因为 $B$ 前面有个减号：

$$4 - B = 7$$

目标仍然是"把 4 弄走"，所以**两边同减 4**：

$$4 - B - 4 = 7 - 4$$

$$-B = 3$$

到这里左边是 $-B$，不是我们想要的 $B$。**两边同乘（或同除以）$-1$**：

$$(-B) \times (-1) = 3 \times (-1)$$

$$B = -3$$

验算：左边 $4 - (-3) = 4 + 3 = 7$，和右边相等。（负数运算见 [13. 负数](13-负数.md)。）

!!! tip "补充（视频未讲）：$4 - B - 4$ 和 $4 - 4 - B$ 一样吗"

    一样，结果都是 $-B$。但依据不是"减法可以随便换顺序"，而是先把减法改写成加法：

    $$4 - B - 4 = 4 + (-B) + (-4)$$

    这三项都是加法，可以任意交换、结合：

    $$4 + (-B) + (-4) = 4 + (-4) + (-B) = 0 + (-B) = -B$$

    而 $4 - 4 - B = (4 - 4) - B = 0 - B = -B$，也是同样的结果。

    笔记写 $4 - B - 4$ 是为了对应"两边同减 4"这个动作；写成 $4 - 4 - B$ 只是先把常数合并，两种顺序都可以。

    !!! warning "但不能随意改变分组"

        减法是**左结合**的：$a - b - c$ 表示 $(a - b) - c$，不能读成 $a - (b - c)$。

        $$4 - (B - 4) = 4 - B + 4 = 8 - B \neq -B$$

        所以"顺序不影响"只在把整个式子看成"若干**带符号的数**相加"时才成立；一旦改变项的归属，就要重新分配符号。

!!! warning "为什么不能一开始就把 $B$ 移过去"

    看到 $4 - B = 7$，容易心想"把 $-B$ 移过去变成 $+B$"，直接写成 $4 = 7 + B$、$B = -3$——结果碰巧是对的，但中间跳步容易把符号弄错。

    按视频的做法：**先减 4，得到 $-B = 3$，再把系数 $-1$ 除掉**，每一步都有依据，出错时也容易查。

## 五、两步及以上：按 PEMDAS 的反顺序撤销

$4 - B = 7$ 需要两步，视频借此总结出一条通用规则：

> **如果一个方程要撤销多个运算，就按 PEMDAS 的相反顺序来。**

也就是：

1. **先撤销加、减**；
2. **再撤销乘、除**。

为什么是反顺序？因为在建算式时，运算是按 PEMDAS 的顺序一层层套到 $x$ 上的；要把它拆开，自然得从**最外层**开始，由外向内剥。

```
建的时候（由内向外）：       解的时候（由外向内）：
  B                            4 - B = 7
   ↓ × (−1)                     ↓ 先减 4
  −B                            −B = 3
   ↓ + 4                        ↓ 再乘 (−1)
  4 − B = 7                     B = −3
```

!!! tip "补充（视频未讲）：为什么"先加减后乘除""

    以 $3x + 7 = 16$（下一节的例子）来说明：$x$ 先被乘 3，再被加 7。加 7 是**最后套上去的一层**，所以最先撤销——两边减 7，得 $3x = 9$，再除以 3。

    反过来先除以 3 也能算，但要把整个左边（包括 7）都除以 3，会冒出一堆分数，越算越乱。所以"先加减后乘除"不是硬性规定，而是**最省事、最不容易错**的顺序。

## 六、解完要检验（补充）

视频没有专门讲检验，但它是解方程最便宜的自检手段：**把求出的解代回原方程**，看左右两边是否相等。

| 方程 | 解 | 代入左边 | 右边 | 是否相等 |
| --- | --- | --- | --- | --- |
| $x + 2 = 5$ | $3$ | $3 + 2 = 5$ | $5$ | ✅ |
| $N - 4 = 17$ | $21$ | $21 - 4 = 17$ | $17$ | ✅ |
| $4D = 20$ | $5$ | $4 \times 5 = 20$ | $20$ | ✅ |
| $\dfrac{Y}{8} = 3$ | $24$ | $24 \div 8 = 3$ | $3$ | ✅ |
| $4 - B = 7$ | $-3$ | $4 - (-3) = 7$ | $7$ | ✅ |

检验能抓住绝大多数符号错误和算术错误。以后方程越复杂，检验越值得做。

## 七、与中国教材"移项"的对应（补充）

中国初中教材里讲的是**移项要变号**：把方程左边的项"移到"右边，符号要反过来。

比如：

$$x + 2 = 5 \quad \longrightarrow \quad x = 5 - 2$$

$$N - 4 = 17 \quad \longrightarrow \quad N = 17 + 4$$

$$4 - B = 7 \quad \longrightarrow \quad -B = 7 - 4$$

**移项不是魔法，它就是"两边同时做同样的运算"的简写。**

- $x + 2 = 5$：两边同减 2，左边的 $+2$ 消失，右边多出 $-2$ ——看起来就像 $+2$ 搬到右边变成了 $-2$；
- $N - 4 = 17$：两边同加 4，左边的 $-4$ 消失，右边多出 $+4$ ——看起来像 $-4$ 搬过去变成 $+4$。

所以"移项变号"的完整依据是：**等式两边同加/同减同一个数，等式不变**。知道这一点，就不会出现"移项忘变号"的错误——因为那相当于只对一边做了运算。

## 八、小结：解方程的标准流程

1. **看清未知数上套了哪些运算**；
2. **从最外层开始撤销**（加减先于乘除）；
3. **每一步都记着：两边同时做**；
4. **代回去检验**。

## 九、核心总结

```
        x + 2 = 5
           │
      x 被加了 2
           │
   两边同时减 2（逆运算）
           │
        x = 3
           │
      代回去检验 ✅
```

| 知识点 | 说明 |
| --- | --- |
| 方程 | 含等号、含未知数的等式 |
| 解 | 使方程成立的未知数的值 |
| 等式性质 | 两边同做相同运算，等式仍成立 |
| 逆运算 | 加↔减、乘↔除（除数非零） |
| 撤销顺序 | 与 PEMDAS 相反：先加减，再乘除 |
| 移项 | 两边同加减的简写；移项要变号 |
| 检验 | 把解代回原方程，两边应相等 |

> **一句话总结**：解方程就是"一层层剥掉套在 $x$ 上的运算"——每剥一层，都要在等式两边同时做同一件事。

## 注释

[^1]: **为什么两边做同样的事，等式仍然成立？** 等式表示两边是**同一个值**。既然两边数值相同，对它们施加同一个函数（加同一个数、乘同一个非零数等），结果当然也相同。用符号写就是：若 $a = b$，则 $f(a) = f(b)$。

    这里有个前提：**除数不能为 0**，因为除以 0 没有定义。所以等式性质里"两边同除以一个数"总是附带"这个数不为 0"。

[^2]: **"解"一定只有一个吗？**

    - 本节的都是一次方程（$x$ 的最高次数是 1），正常情况下恰好一个解。
    - 平方方程可能有两个解，例如 $x^2 = 9$ 有 $x = 3$ 和 $x = -3$（见 [27. 平方根、立方根和其他根](27-平方根、立方根和其他根.md)）。
    - 方程也可能**无解**或**有无数个解**——这种"两边 $x$ 项完全相同或恰好抵消"的情况，会在 [24. 两边都有变量的方程](24-两边都有变量的方程.md) 里补充。
