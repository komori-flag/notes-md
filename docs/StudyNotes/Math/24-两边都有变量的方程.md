上一节的方程只有一个运算套在 $x$ 上，一步就能解开。这一节处理两类更麻烦的情形：

1. $x$ 上套了**两个**运算（如 $3x + 7 = 16$）——要决定先拆哪一层；
2. **等式两边都有 $x$**（如 $4x + 3 = x - 6$）——要先把 $x$ 集中到一边。

再加一个"括号 + 分数"的混合例子，把 [22. 代数中的基本运算性质](22-代数中的基本运算性质.md) 里的工具全用上。

## 一、先拆哪一层：$3x + 7 = 16$

这里 $x$ 同时参与了乘法和加法：先被乘 3，再被加 7。

**如果先除以 3**，两边都要除以 3——注意是**整个左边**都要除，不只是 $3x$：

$$\frac{3x + 7}{3} = \frac{16}{3}$$

$$x + \frac{7}{3} = \frac{16}{3}$$

$$x = \frac{16}{3} - \frac{7}{3} = \frac{9}{3} = 3$$

算得出来，但视频的评价是"把事情弄得更糟"（that just made things worse）——凭空多了分数，还要通分，凭空增加出错机会。

**如果先减 7**，就干净得多：

$$3x + 7 - 7 = 16 - 7$$

$$3x = 9$$

$$\frac{3x}{3} = \frac{9}{3}$$

$$x = 3$$

所以视频总结出的策略是：

> **解方程时，通常先做加减（撤销加减），再做乘除（撤销乘除）。**

这和上一节"按 PEMDAS 的反顺序撤销"是同一条规则，只是这里把原因讲清楚了[^1]。

!!! tip "补充（视频未讲）：为什么这样最省事"

    把 $3x + 7$ 想象成一件"包了两层的包裹"：$x$ 先被包上"乘 3"，再被包上"加 7"。外面的那层是加法，先拆它，剩下的就是清清爽爽的 $3x = 9$。

    先拆里面那层（除以 3）不是不行，但等于把外层也一起"除"了，每项都要除以 3，包裹没拆干净，反而多出一堆分数。

## 二、两边都有 $x$：$4x + 3 = x - 6$

这个方程里 $x$ 出现了两次。目标是**把 $x$ 项全部集中到一边，数字全部集中到另一边**，最后剩一个单独的 $x$。

### 2.1 先把 $x$ 项集中

右边有一个 $x$，两边同减 $x$：

$$4x - x + 3 = x - x - 6$$

左边出现 $4x - x$，可以**合并同类项**：

$$4x - x = 3x$$

右边 $x - x = 0$，$x$ 项整个消失：

$$3x + 3 = -6$$

### 2.2 合并同类项时，字母不会消失

视频专门提醒：$4x - x = 3x$，**不是 3**。$x$ 是两项共同的"单位"，就像：

> 4 个苹果减 1 个苹果 = 3 个**苹果**，不是 3。

$$4x - x = (4 - 1)x = 3x$$

括号里做的只是系数相减，$x$ 原样保留。依据是反向分配律（见 [22. 代数中的基本运算性质](22-代数中的基本运算性质.md)）[^2]。

### 2.3 再把数字集中

$$3x + 3 = -6$$

两边同减 3：

$$3x = -9$$

两边同除以 3：

$$x = -3$$

### 2.4 检验

左边：$4 \times (-3) + 3 = -12 + 3 = -9$；右边：$-3 - 6 = -9$。两边相等 ✅

## 三、更复杂的例子：括号 + 分数

$$\frac{3 - 3x}{4} = 3(2x + 1)$$

这个方程左右两边都有 $x$，左边是分数，右边有括号。视频把它拆成五步。

### 3.1 先去括号（右边）

$$3(2x + 1) = 3 \cdot 2x + 3 \cdot 1 = 6x + 3$$

方程变成：

$$\frac{3 - 3x}{4} = 6x + 3$$

### 3.2 再去分母（两边乘 4）

两边同乘 4：

$$\frac{3 - 3x}{4} \times 4 = 4(6x + 3)$$

左边 4 约掉，右边乘 4 时要**把整个右边放到括号里乘**：

$$3 - 3x = 24x + 12$$

!!! warning "乘 4 时最容易漏的两处"

    - 右边 $6x + 3$ **两项都要乘 4**：$4(6x+3) = 24x + 12$，不是 $24x + 3$。
    - 左边分子 $3 - 3x$ 是一个整体，约掉 4 之后**原样保留**，不要只约掉 $3x$ 或其中的某一项。

### 3.3 把 $x$ 项集中

两边同加 $3x$（把左边的 $-3x$ 移到右边）：

$$3 = 24x + 3x + 12$$

$$3 = 27x + 12$$

### 3.4 把数字集中

两边同减 12：

$$-9 = 27x$$

### 3.5 系数化为 1

习惯上把未知数写在左边，所以视频把等式**左右对调**（这不改变任何东西，只是换个读法[^3]）：

$$27x = -9$$

两边同除以 27：

$$x = \frac{-9}{27} = -\frac{1}{3}$$

### 3.6 检验

$$x = -\frac{1}{3} \text{ 时，左边 } \frac{3 - 3 \times (-\frac{1}{3})}{4} = \frac{3 + 1}{4} = 1$$

$$\text{右边 } 3\left(2 \times (-\frac{1}{3}) + 1\right) = 3\left(-\frac{2}{3} + 1\right) = 3 \times \frac{1}{3} = 1$$

两边都是 1 ✅

## 四、"把分母提上去"：一个实用的想法

视频在第 3.2 步提了一个简化思路，值得单独记住：

> **一边分母里的数，可以直接"提"到另一边的分子上；一边分子里的数，也可以"放"到另一边的分母里。**

在这里，左边的分母 4 提到右边，就变成：

$$\frac{3 - 3x}{4} = 6x + 3 \quad \longrightarrow \quad 3 - 3x = 4(6x + 3)$$

这**本质上就是两边同乘 4**：左边乘 4 把分母约掉，右边乘 4 就多出一个 4。但省去了"写 4、约 4"的中间步骤。

!!! warning "提上去的时候必须加括号"

    提出来的 4 要乘的是**另一边的整个表达式**，所以必须写成 $4(6x + 3)$，不能写成 $4 \cdot 6x + 3$。

    视频特意强调"make sure to put it outside of some parentheses"。漏掉括号，等于只乘了第一项。

!!! note "这个技巧的适用边界"

    "分母提到另一边"只在**两边都是等式的一部分**时成立，因为它实质上是两边同乘。

    - 如果一边是**两个分数相加**，比如 $\dfrac{a}{4} + \dfrac{b}{4}$，提分母的思路要更小心（通常是先合并或通分）。
    - 如果**两边都有分母**，相当于交叉相乘（cross-multiply）：$\dfrac{a}{b} = \dfrac{c}{d} \Rightarrow ad = bc$。前提是 $b, d \neq 0$。

## 五、整理成固定流程（补充）

中国教材把解一元一次方程总结成五步，和视频的做法一一对应：

| 步骤 | 做什么 | 本例中的体现 |
| --- | --- | --- |
| 1. 去分母 | 两边同乘各分母的最小公倍数 | 两边乘 4 |
| 2. 去括号 | 用分配律把括号展开 | 右边 $3(2x+1) \to 6x+3$ |
| 3. 移项 | 把含 $x$ 的项移到一边、常数移到另一边（移项变号） | 加 $3x$、减 12 |
| 4. 合并同类项 | 把同类项系数相加 | $24x + 3x = 27x$ |
| 5. 系数化为 1 | 两边同除以 $x$ 的系数 | 除以 27 |

!!! tip "顺序可以灵活"

    教材默认"先去分母、再去括号"，是因为分母外的乘数往往也要乘进括号里（如 $\dfrac{2x+1}{3} \times 6$），先清分母能避免一边去括号一边又要乘分数。

    但本例的分母只出现在左边、且左边分子已经是展开的 $3 - 3x$，所以视频选择**先去括号再去分母**，同样正确。

    原则只有一条：**每一步都必须是两边同时做，且乘的时候覆盖整块。**

## 六、$x$ 整个消掉了怎么办（补充）

上一节说一次方程通常有一个解。但移项合并之后，$x$ 的系数可能变成 0，这时会出现两种特殊情况。

### 6.1 无解

$$2x + 3 = 2x + 5$$

两边同减 $2x$：

$$3 = 5$$

这是一个**假命题**。无论 $x$ 取什么值，都不能让 $3$ 等于 $5$，所以方程**无解**。

### 6.2 有无数个解

$$2x + 3 = 2x + 3$$

两边同减 $2x$：

$$3 = 3$$

这是**恒真命题**。无论 $x$ 取什么值都成立，所以方程有**无数个解**（这样的方程叫恒等式）。

!!! note "怎么识别"

    把含 $x$ 的项都移到一边、合并之后：

    - 得到 $0 = \text{非零数}$ → 无解；
    - 得到 $0 = 0$ → 无数个解；
    - 得到一个非零系数乘 $x$ → 正常的一个解。

    视频本节的例子都属于第三种，但实际做题时会遇到前两种，尤其是带参数的问题。

## 七、核心总结

```
            4x + 3 = x − 6
                  │
       两边同减 x（集中 x 项）
                  │
        3x + 3 = −6
                  │
      合并同类项：4x − x = 3x
                  │
        3x = −9   （两边同减 3）
                  │
         x = −3   （两边同除以 3）
                  │
            代回检验 ✅
```

| 知识点 | 说明 |
| --- | --- |
| 撤销顺序 | 先加减、后乘除；先拆最外层 |
| 先拆里面会怎样 | 能算，但要把整边除以系数，分数变多、更容易错 |
| 两边都有 $x$ | 先用加减把 $x$ 项集中到一边 |
| 合并同类项 | $4x - x = 3x$；字母保留，只加减系数 |
| 去分母 | 两边同乘分母；另一边整体加括号 |
| 分数方程技巧 | 分母可"提到"另一边分子上，等价于两边同乘 |
| 特例 | $0 = 0$ 无数解；$0 = 非零$ 无解 |

> **一句话总结**：先把 $x$ 全部赶到一边、数字全部赶到另一边——移项用加减，消系数用乘除，每一步都两边同时做。

## 注释

[^1]: **为什么"先加减后乘除"总能少走弯路？** 因为一个一次方程里，$x$ 通常被这样构造出来：

    $$x \xrightarrow{\times a} ax \xrightarrow{+b} ax + b$$

    最后套上去的是 $+b$，所以最先撤销它，方程就退回 $ax = \text{常数}$ 的简单形态。如果先撤销乘法，等于把 $+b$ 也一起除了，多出一层分数。这就是"由外向内剥"的道理。

[^2]: **合并同类项的依据**：$4x - x = (4-1)x$ 用的是分配律的反向使用 $ab + ac = a(b+c)$，即

    $$4x + (-1)x = (4 + (-1))x = 3x$$

    这里把 $x$ 当作公共因式提出来。所以"合并同类项"不是什么新规则，而是 [22. 代数中的基本运算性质](22-代数中的基本运算性质.md) 里分配律的又一次应用。

[^3]: **两边都对调（flip）为什么合法？** 等号表示两边相等，而相等是**对称**的：$a = b$ 与 $b = a$ 是同一个事实。把 $-9 = 27x$ 写成 $27x = -9$ 不改变任何数值，只是把未知数放到左边，符合我们读方程的习惯。
