到目前为至，代数的核心都是**方程**：左右两边相等，我们移动各项，把变量单独解出来。

这一节介绍方程的一个近亲——**不等式（inequality）**。它不告诉你两边相等，而是告诉你**哪一边更大、哪一边更小**。

好消息是：解不等式的方法和解方程几乎一模一样，只多**一条**小规则。

## 一、不等式在说什么

先看最简单的：

$$x > 3$$

读作"$x$ 大于 3"[^3]。

它和方程有一个根本区别：**方程通常只有一个解，不等式有一整批解。**

任何大于 3 的数都是解：$4$、$10$、十亿、$3.00001$……只要比 3 大就能成立。反过来，小于或等于 3 的数——$0$、$-3$、$2.999$、$3$ 本身——都**不是**解。

### 1.1 数轴上的表示

在数轴上，$x > 3$ 这样画：

```
        ○───────────────►
────────┼────┼────┼────┼────
        1    2    3    4
                  ↑
             空心圆：3 不在解里
```

- **空心圆（open circle）**：表示这个点**不包含**在解里；
- **箭头向右**：表示所有大于 3 的数。

!!! note "四个符号"

    | 符号 | 读法 | 包含端点？ | 数轴上的点 |
    | --- | --- | --- | --- |
    | $>$ | 大于 | 不包含 | 空心 |
    | $<$ | 小于 | 不包含 | 空心 |
    | $\geq$ | 大于或等于 | 包含 | 实心 |
    | $\leq$ | 小于或等于 | 包含 | 实心 |

    视频说 $\geq$、$\leq$ 和其他符号用法相同，唯一的区别是**把端点也算进解里**。

## 二、解法和方程一样

### 2.1 一步：$x + 2 < 7$

$x$ 被加了 2，两边同减 2：

$$x + 2 - 2 < 7 - 2$$

$$x < 5$$

任何小于 5 的数都是解；5 或更大的数不是。

### 2.2 两步：$3x + 4 \geq 16$

先撤销加法——两边同减 4：

$$3x + 4 - 4 \geq 16 - 4$$

$$3x \geq 12$$

再撤销乘法——两边同除以 3（正数，不变号）：

$$x \geq 4$$

数轴上用**实心圆**表示 4 也包含在内：

```
        ●───────────────►
────────┼────┼────┼────┼────
        2    3    4    5
                  ↑
             实心圆：4 在解里
```

可以看到，整个过程和 [23. 代数方程及其解](23-代数方程及其解.md)、[24. 两边都有变量的方程](24-两边都有变量的方程.md) 完全一样：**两边同时做，先加减后乘除**。

## 三、唯一的额外规则：乘除负数要变号

视频专门指出的那条差别是：

> **如果两边同时乘或除以一个负数，不等号的方向要反过来。**[^1]

例子：

$$-x > 6$$

要得到 $x$，两边同乘（或同除以）$-1$。但这时 $>$ 必须变成 $<$：

$$x < -6$$

### 3.1 用具体数字验证

先验证原不等式：取 $x = -10$。

$$-(-10) = 10 > 6 \quad ✅$$

再验证变形后的不等式：同一个 $x = -10$。

$$-10 < -6 \quad ✅$$

两个说法描述的是同一批数，只是写的方式相反。

### 3.2 用整数对验证

$$1 < 2$$

两边同乘 $-1$，如果不变号会得到：

$$-1 < -2 \quad ❌ \text{（错）}$$

正确的写法是把符号反过来：

$$-1 > -2 \quad ✅$$

## 四、为什么要变号

视频给了两条互相印证的思路。

### 4.1 负数的大小方向

先记住 [13. 负数](13-负数.md) 里的规则：**负数越靠近 0 越大。**

所以：

$$-10 < -5 < -1 < 0$$

看起来 $-10$ "数字更大"，实际上它更小——它在数轴上更靠左。

### 4.2 乘 $-1$ 相当于把数轴镜像翻转

- 数轴上每个数乘一个**正数**，只是把整条线拉伸或压缩，左右顺序不变；
- 每个数乘一个**负数**，每个数的符号都翻转，整条线像照镜子一样**左右颠倒**。

顺序颠倒了，原来"左边的更小"就变成"右边的更小"。为了补偿这次镜像，不等号也必须跟着翻过来。

```
   乘 −1 之前：  ────┼────┼────┼────►
                    1    2    3
                  1 < 2

   乘 −1 之后：  ◄────┼────┼────┼────
                   −3   −2   −1
                  −1 > −2   （顺序颠倒）
```

!!! tip "补充（视频未讲）：严格证明"

    设 $a < b$。要证 $-a > -b$。

    因为 $a < b$，所以 $b - a > 0$。而

    $$(-a) - (-b) = b - a > 0$$

    所以 $-a > -b$。

    这说明"乘 $-1$ 变号"不是规定，而是可以由数的大小关系直接推出来的。

## 五、什么时候**不**变号（最容易错）

变号规则只适用于**乘或除以负数**。下面这些操作**都不变号**：

| 操作 | 例子 | 变号？ |
| --- | --- | --- |
| 两边同加一个数（包括负数） | $x - 3 < 2 \Rightarrow x < 5$ | ❌ 不变 |
| 两边同减一个数（包括负数） | $x + (-2) > 1 \Rightarrow x > 3$ | ❌ 不变 |
| 两边同乘/除以**正数** | $2x < 8 \Rightarrow x < 4$ | ❌ 不变 |
| 两边同乘/除以**负数** | $-2x < 8 \Rightarrow x > -4$ | ✅ 变号 |

!!! warning "两个高频错误"

    **错误一：加减负数也变号。**

    $$-x > 6 \quad \text{两边加 } 1 \quad \Rightarrow \quad -x + 1 > 7$$

    这里加的是 $+1$，不是乘除，**不能变号**。

    **错误二：只把不等号翻过来，数字也乱改。**

    $$-2x < 8 \quad \Rightarrow \quad x > -4$$

    变号只发生在**不等号符号**上，数字的运算照常：$8 \div (-2) = -4$，不变。

## 六、完整例子：先移项，再变号（补充）

$$3 - x \geq 5$$

两边同减 3（不变号）：

$$-x \geq 2$$

两边同乘 $-1$（**变号**）：

$$x \leq -2$$

检验：取 $x = -3$，原式左边 $3 - (-3) = 6 \geq 5$ ✅；且 $-3 \leq -2$ ✅。

这个例子把两种操作串在一起：**移项时不变号，最后除系数时如果是负数才变号。**[^2]

## 七、解的检验与区间记法（补充）

### 7.1 用测试点检验

解完不等式后，从解集里挑一个数代回原不等式，看是否成立。比如 $x \geq 4$，取 $x = 5$：

$$3 \times 5 + 4 = 19 \geq 16 \quad ✅$$

再从不该属于解集的区域挑一个，如 $x = 3$：

$$3 \times 3 + 4 = 13 \geq 16 \quad ❌ \text{（确实不成立）}$$

两头都试，能同时查出方向错误和端点错误。

### 7.2 区间记法

不等式的解集也可以用区间写：

| 不等式 | 区间 | 含义 |
| --- | --- | --- |
| $x > 3$ | $(3, +\infty)$ | 3 不包含（圆括号） |
| $x \geq 4$ | $[4, +\infty)$ | 4 包含（方括号） |
| $x < -6$ | $(-\infty, -6)$ | $-6$ 不包含 |
| $x \leq -2$ | $(-\infty, -2]$ | $-2$ 包含 |

方括号对应实心圆，圆括号对应空心圆——记法不同，含义相同。

## 八、核心总结

```
        解不等式
           │
   和方程一样：两边同时做
   先加减，后乘除
           │
   ┌───────┴────────┐
   │                │
 乘/除正数        乘/除负数
   │                │
 不变号           变号（> ↔ <，≥ ↔ ≤）
   │                │
   └───────┬────────┘
           │
     数轴表示：空心 / 实心
```

| 知识点 | 说明 |
| --- | --- |
| 不等式 | 表示大小关系，不是相等 |
| 解集 | 通常有无数个值；端点是否包含看符号 |
| 解法 | 与方程相同：两边同时做，先加减后乘除 |
| 变号规则 | 两边同乘/除以负数时，不等号反向 |
| 不变号 | 加减任何数、乘除正数，都不变号 |
| 数轴 | 空心圆 = 不包含，实心圆 = 包含 |
| 检验 | 从解集内外各取一个测试点代入 |

> **一句话总结**：解不等式就是解方程，只在"两边乘或除以负数"这一步把不等号翻个方向——因为乘负数会把整条数轴镜像翻转。

## 注释

[^1]: **为什么方程不需要这条规则？** 因为方程用的是等号，等号是**对称**的：$a = b$ 时，无论乘什么（包括负数），两边仍然相等。不等号是有方向的，乘负数会颠倒大小关系，所以必须把方向也翻过来。

[^2]: **$\geq$ 和 $\leq$ 变号时变成什么？** 互相变成对方：$\geq$ 变 $\leq$，$\leq$ 变 $\geq$。例如

    $$-2x \geq 6 \quad \Rightarrow \quad x \leq -3$$

    规律是"**大于变小于，小于变大于，等号部分不变**"。

[^3]: **"$x > 3$"和"$3 < x$"是一回事。** 把整个不等式左右对调，等价于两边同时乘 $-1$ 再整理，所以方向也要反过来。读法上，两者都表示"$x$ 比 3 大"。
