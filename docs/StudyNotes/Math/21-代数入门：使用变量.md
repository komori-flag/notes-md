前面二十节一直在做**算术（arithmetic）**：给定数字，算出结果。这一节开始换赛道，进入**代数（algebra）**。

视频开头的调侃很形象：学校里一直学的那门课就叫"数学"，直到某一天，它突然不叫数学了，改叫"代数"。听起来像跨了一道坎，其实代数并没有引入新的运算法则——它只是**用字母来表示数**，而这些字母的含义完全可以理解得很直觉。

## 一、变量（Variable）

> 变量：一个字母或符号，代表**可以改变**的量。

变量可以代表任何东西：

- 你所在城市某个月的降雨量（inches of rain）
- 汽油的价格（the price of gasoline）
- 飞机的速度（the speed of a plane）

只要是你想拿来做数学的对象，都可以给它起个字母当名字。

### 1.1 变量和常量是一对

> 常量（constant）：一个字母或符号，代表**不会改变**的量。

两者的区别只有一个字：**变**。

| | 变量 variable | 常量 constant |
| --- | --- | --- |
| 代表 | 可以改变的量 | 固定不变的量 |
| 常见写法 | $x,\ y,\ z$ | $a,\ b,\ c$ 或具体数字 |
| 例子 | 你每天看电视的小时数 | 圆周率 $\pi \approx 3.14$ |

!!! note "常量不一定写成数字"

    视频定义常量时说的是"字母或符号"，不是"数字"。$\pi$ 就是一个典型：它是字母，但它代表的值永远是 $3.14159\dots$，不会变。

    写成字母而不是数字，往往是因为**这个数太长、写不下**（如 $\pi$），或者**它的精确值对这个问题的答案没有影响**（如后面常用的 $g$、$e$）。

!!! tip "补充（视频未讲）：常量和变量是相对于"问题"而言的"

    在 $y = 3x$ 这个关系里，$3$ 是常量——它表示"每个汉堡 3 美元"这条前提，在这个问题里固定不变；$x$ 和 $y$ 是变量。

    换一个问题，"3" 完全可能变成变量（比如不同店里每个汉堡的单价不同，那单价就该用字母表示）。所以判断一个量是变量还是常量，要先看**当下的问题里它会不会变**。

## 二、代数式（Algebraic Expression）

算术式里只有**数字和运算**：

$$3 \times 5 + 2$$

代数式里**一定含有一个或多个变量**，同时也可以有数字和运算：

$$3x + 2$$

这就是一个代数式。它读作"3x 加 2"。

### 2.1 省掉乘号

$3x$ 的意思就是 $3 \times x$。代数的约定是：**一个数和字母相乘时，乘号可以省略**，直接并排写。[^1]

$$3x + 2 \quad \text{就是} \quad 3 \times x + 2$$

!!! warning "只有"数 × 字母"才能省乘号"

    - $3x$ ✅ 表示 $3 \times x$
    - $xy$ ✅ 表示 $x \times y$
    - $3 \times 5$ ❌ **不能**写成 $35$——那就变成三十五了

    纯数字之间必须写乘号，否则两个数会连成一个新的数。省略乘号靠的是"数字和字母一眼就能分开"这一点。

!!! tip "补充（视频未讲）：写法的两个习惯"

    - **数字写在字母前面**：写 $3x$，不写 $x3$。
    - **系数是 1 时省略不写**：$1x$ 直接写 $x$；$x$ 的系数就是 1。

    $3x$ 里的那个 $3$ 有个正式名字叫**系数（coefficient）**，指字母前面乘着的那个数。

## 三、求值（Evaluate）：把数字代进去

给定一个代数式，只要**指定 $x$ 的值**，就能算出这个式子等于多少——这个过程叫**求值（evaluate）**。做法就是把字母替换成数字，然后照算术的规矩算。

以 $3x + 2$ 为例：

| $x$ | 代入后的式子 | 计算 | 结果 |
| --- | --- | --- | --- |
| 1 | $3 \times 1 + 2$ | $3 + 2$ | **5** |
| 2 | $3 \times 2 + 2$ | $6 + 2$ | **8** |
| 3 | $3 \times 3 + 2$ | $9 + 2$ | **11** |
| 4 | $3 \times 4 + 2$ | $12 + 2$ | **14** |

$x = 1$ 时，代入得 $3 \times 1 + 2 = 5$；$x = 2$ 时得 $6 + 2 = 8$；以此类推。

### 3.1 求值时运算顺序照旧

$3x + 2$ 里，**乘法先做，加法后做**——这正是 [15. 算术运算顺序](15-算术运算顺序.md) 的规则。

$x = 2$ 时：先算 $3 \times 2 = 6$，再加 $2$，得 $8$。绝不能先算 $2 + 2 = 4$ 再乘 $3$。[^2]

### 3.2 观察表格里的规律

看"结果"那一列：$5, 8, 11, 14, \dots$ 每多一行就**加 3**。

原因是 $x$ 每增加 1，$3x$ 就增加 3，而后面那个 $+2$ 是常量，不受影响。这个"每增加 1 就变化多少"的规律，就是以后**斜率**的雏形。

## 四、用代数描述现实（Model）

求值只是"给定 $x$ 算 $y$"。代数真正有用的地方，是能**把现实中的数量关系写成一个式子**，从而回答一整类问题，而不是一次性的一个问题。

视频给了两个例子。

### 4.1 汉堡：从"算一次"到"算任意次"

**只用算术**，你只能说：

> 5 个汉堡，每个 3 美元，一共 15 美元。

$$5 \times 3 = 15$$

但换个数（7 个？12 个？）就得重算一遍，问题也只是"这一次"的。

**用代数**，先设字母：

- $x$ = 汉堡的个数（the number of cheeseburgers）
- $y$ = 总价（the total cost）

然后写出这条关系：

$$y = 3x$$

一次性把"总价 = 3 美元 × 个数"这件事说清楚了。想知道 5 个多少钱？令 $x = 5$：

$$y = 3 \times 5 = 15$$

和算术得到的 15 一致。想知道 12 个多少钱？令 $x = 12$，得 $y = 36$。

!!! note "两种做法的本质差别"

    - **算术**是一台"一次性计算器"：输入具体数字，输出一个答案。
    - **代数**是一台"可复用的机器"：先建立**数量之间的关系**，之后任何输入都能取用。

    所以视频说，代数让我们能"对现实情境做各种相关的计算"，而不只是算出一个数。

### 4.2 Bobo 看电视：关系里带"倍数 + 偏移"

再看一个稍复杂的设定：

> 你很喜欢看电视，但你朋友 Bobo 看得比你还多——**不管你看多少，Bobo 都看你的两倍，再多一个小时**。

设：

- $x$ = 你今天看电视的小时数
- $y$ = Bobo 今天看电视的小时数

那么：

$$y = 2x + 1$$

"两倍再加一"，字面翻译成式子就是 $2x + 1$。

| 你（$x$） | 计算 $2x + 1$ | Bobo（$y$） |
| --- | --- | --- |
| 1 小时 | $2 \times 1 + 1$ | 3 小时 |
| 2 小时 | $2 \times 2 + 1$ | 5 小时 |
| 3 小时 | $2 \times 3 + 1$ | 7 小时 |
| 0 小时 | $2 \times 0 + 1$ | 1 小时 |

注意 $x = 0$ 这一行：你一小时都没看，Bobo 还是看了 1 小时——因为"额外再加一小时"这部分与你的 $x$ 无关，它是常量。

!!! tip "补充（视频未讲）：式子里的每个部分都有含义"

    把 $y = 2x + 1$ 拆开看：

    - $2$ 是**倍数**：Bobo 是你的两倍——这是系数；
    - $+1$ 是**固定的偏移**：他总比"两倍"多一小时——这是常量项。

    读式子时可以逐块翻译回口语，这是"把文字变成式子"和"把式子读回文字"的双向练习。本节两个例子的结构完全相同，只是数字不同：

    $$y = 3x \qquad\text{vs}\qquad y = 2x + 1$$

    都是"常量 × 变量 + 常量"的形状，也就是以后的一次函数 $y = kx + b$。

## 五、表达式与方程：一个容易混的区分

视频里"algebraic expression（代数式）"和"algebraic equation（代数方程）"两个说法交替出现，口语上没问题，但严格来说它们不是一回事：

| | 代数式 expression | 方程 equation |
| --- | --- | --- |
| 长什么样 | $3x + 2$ | $y = 3x$ |
| 有没有等号 | 没有 | 有 |
| 说的是什么 | 一个**量** | 两个量**相等**的一个断言 |
| 能做什么 | 代入求值 | 可以"解"出未知数 |

$$3x + 2 \quad\text{是表达式}$$

$$y = 3x \quad\text{是方程}$$

!!! note "为什么这个区分重要"

    表达式本身给不出"答案"，它只是"一个值"。方程才带**约束**——"这两边相等"——而约束才可能推出未知数的值。

    后面几节要学的"解方程"（下一节往后），解的对象永远是**方程**，不是表达式。

## 六、字母为什么能"直觉"

视频说可以"让这些符号变得直觉"（make these symbols intuitive）。有三条理由：

**1. 字母是"占位符"。** $x$ 只是一个位置，等着被填进一个具体数字。求值就是把数字填进去。

**2. 同一个字母，在同一个问题里永远代表同一个数。** 这条一致性是代数能够推理的前提。比如 $3x + 2$ 里的 $x$ 不是"随便一个数"，而是"这次计算所指定的那个数"。如果同一个式子里出现两个 $x$，它们必须取相同的值——否则就不是同一个变量了。

**3. 约定俗成让符号能"自解释"。** 常见约定：

| 字母 | 通常代表 |
| --- | --- |
| $x,\ y,\ z$ | 未知量、变量 |
| $a,\ b,\ c$ | 已知的常量、系数 |
| $t$ | 时间 |
| $n$ | 个数、个数类的整数（如 [20. 极差、平均数、中位数与众数](20-极差、平均数、中位数与众数.md) 里的 $n$） |
| $d$ | 距离、直径 |

!!! note "字母代表的是数，所以运算法则原封不动"

    变量不是新种类的对象，它只是**数的替身**。因此 [10. 算术的分配律](10-算术的分配律.md) 这样的规律对字母照样成立：

    $$3(x + 2) = 3x + 6$$

    左边是"3 乘一个和"，右边是分配开之后的结果。$x$ 取任何值，两边都相等。这就是为什么先学好算术，学代数时不用重学一遍规矩。

## 七、算术与代数的对比

| | 算术 arithmetic | 代数 algebra |
| --- | --- | --- |
| 处理对象 | 具体的数字 | 数字，以及代表数字的字母 |
| 一个式子 | $5 \times 3 = 15$ | $y = 3x$ |
| 回答的问题 | 这一次等于多少 | 这几个量之间是什么关系 |
| 可复用性 | 一次 | 任意次 |
| 主要动作 | 计算 | 建模、求值、解方程 |

## 八、核心总结

```
        数 学
          │
   ┌──────┴──────┐
   │             │
 算术           代数
 只有数字     数字 + 字母
   │             │
 算出一个答案  写出一种关系
               （可代入任意值）
```

| 知识点 | 说明 |
| --- | --- |
| 变量 | 代表**会变**的量的字母或符号 |
| 常量 | 代表**不变**的量的字母或符号（如 $\pi$） |
| 代数式 | 含一个或多个变量的式子，如 $3x + 2$ |
| 省略乘号 | $3x = 3 \times x$；但 $3 \times 5$ 不能写成 $35$ |
| 系数 | 字母前面乘着的数，$3x$ 的系数是 3 |
| 求值 | 把字母换成指定数字，按运算顺序算 |
| 建模 | 把现实关系写成方程，如 $y = 3x$、$y = 2x + 1$ |
| 表达式 vs 方程 | 表达式无等号；方程有等号、可以解 |

> **一句话总结**：算术是"给定数字算一个答案"，代数是"用字母写出一条关系"——同一条关系能代入任意数字，所以能回答一整类问题，而不只是这一次。

## 注释

[^1]: **为什么可以省略乘号？** 一个实用原因是：手写时字母 $x$ 和乘号 $\times$ 长得太像，$3 \times x$ 容易看成 $3xx$ 或干脆看糊。省掉乘号既避免了歧义，也少写一个符号。

    数学史上这个写法是逐步固定下来的：笛卡尔（René Descartes）在 17 世纪用 $x$、$y$、$z$ 表示未知量、$a$、$b$、$c$ 表示已知量，并推广了"并排即相乘"的记法，今天的代数记号基本沿用他的选择。

[^2]: **求值时的常见错误。**

    - **顺序错**：$3x + 2$ 在 $x=2$ 时应先乘后加得 $8$，写成 $(3+2)x = 10$ 就错了。
    - **负号漏掉**：$x = -1$ 时，$3x + 2 = 3 \times (-1) + 2 = -3 + 2 = -1$（负数运算见 [13. 负数](13-负数.md)）。
    - **分数要加括号**：$x = \dfrac{1}{2}$ 时，$3x = 3 \times \dfrac{1}{2} = \dfrac{3}{2}$（分数乘法见 [19. 分数的乘法与除法](19-分数的乘法与除法.md)）。

    变量能取的值不止正整数——这正是代数的力量所在，代入时把算术里的规则一条条都用上即可。
