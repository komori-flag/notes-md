## 一、什么是指数（Exponent）？

在加法、减法、乘法、除法四种基本运算之后，指数是下一种重要运算，用来表示**重复进行乘法**（Repeated Multiplication）——正如乘法表示重复加法一样。

**基本结构**：$a^b$

- $a$：**底数**（Base）
- $b$：**指数**（Exponent / Power）

例如 $2^3$ 表示 $2 \times 2 \times 2 = 8$。

**常见名称**：

- 指数为 2 → **平方**（Square）：$5^2$ 读作"五的平方"，$5 \times 5 = 25$
- 指数为 3 → **立方**（Cube）：$5^3$ 读作"五的立方"，$5 \times 5 \times 5 = 125$

**另一种表示方式**：无法输入上标时用 `^` 符号，例如 `5^4` 表示 $5^4 = 625$——`^` 左边是底数，右边是指数。

## 二、指数增长（Exponential Growth）

指数最大的特点：**数值增长速度非常快**。

**国际象棋棋盘米粒传说**：一个国王奖励发明国际象棋的人，数学家提出要求：第一格放 1 粒米，第二格 2 粒，第三格 4 粒……每一格都是上一格的两倍。

| 棋盘位置 | 米粒数量 |
| --- | --- |
| 第 1 格 | $2^0 = 1$ |
| 第 2 格 | $2^1 = 2$ |
| 第 3 格 | $2^2 = 4$ |
| 第 4 格 | $2^3 = 8$ |
| 第 5 格 | $2^4 = 16$ |

指数每增加 1，数量都 $\times 2$。最终第 64 格：

$$2^{63} > 9 \times 10^{18}$$

粒米——足够用一米厚的米层覆盖整个印度，全世界都拿不出这么多米。指数增长会产生**巨大数量级变化**。

## 三、指数计算实例

**示例 1**：$3^4 = 3 \times 3 \times 3 \times 3 = 81$

**示例 2**：$6^5 = 6 \times 6 \times 6 \times 6 \times 6 = 7776$

## 四、负指数（Negative Exponents）

指数不仅可以是正数，也可以是负数。

**规则**：$a^{-n} = \dfrac{1}{a^n}$（将数字倒置取倒数，然后使用正指数）

例：

$$2^{-2} = \frac{1}{2^2} = \frac{1}{4}$$

## 五、指数运算规则（Exponent Rules）

**规则 1：同底数相乘 → 指数相加**

$$x^a \times x^b = x^{a+b}$$

原因：$x^2 \times x^3 = (x \times x)(x \times x \times x) = 5$ 个 $x$ 连乘 $= x^5$。

**规则 2：同底数相除 → 指数相减**

$$\frac{x^a}{x^b} = x^{a-b}$$

原因：$\dfrac{x^5}{x^3}$ 上下抵消 3 个 $x$，剩 $x^2$。

**规则 3：负指数的来源**

$$\frac{x^5}{x^7} \Rightarrow 抵消 5 个，剩 \frac{1}{x^2}，而 5 - 7 = -2 \Rightarrow x^{-2} = \frac{1}{x^2}$$

**规则 4：零指数 → 任何非零数的 0 次方等于 1**

$$x^0 = 1$$

原因：$\dfrac{x^3}{x^3} = x^{3-3} = x^0$，而 $\dfrac{x^3}{x^3} = 1$。

例：$5^0 = 1$，$100^0 = 1$。

**规则 5：幂的幂 → 指数相乘**

$$(x^a)^b = x^{ab}$$

原因：$(x^4)^2 = (x^4)(x^4) = 8$ 个 $x$ 连乘 $= x^8 = x^{4 \times 2}$。

## 六、不能合并的情况（常见错误）

!!! warning "易错点"

    $x^a + x^b$ **没有**指数规则可以化简——它们是两个不同的项，不能合并。

    错误：$x^2 + x^3 \neq x^5$

    只有 $x^a \times x^b$ 或 $\dfrac{x^a}{x^b}$ 才可以合并指数。

## 七、指数规则总结表

| 类型 | 公式 | 口诀 |
| --- | --- | --- |
| 同底数相乘 | $x^a x^b = x^{a+b}$ | 指数相加 |
| 同底数相除 | $\dfrac{x^a}{x^b} = x^{a-b}$ | 指数相减 |
| 幂的幂 | $(x^a)^b = x^{ab}$ | 指数相乘 |
| 负指数 | $x^{-a} = \dfrac{1}{x^a}$ | 倒数变正 |
| 零指数 | $x^0 = 1$ | 非零数 0 次方为 1 |

> **学习重点**：指数就是一种快速表示重复乘法的方法。理解指数规则的关键，是把指数看成"有多少个相同因子相乘"。
