## 一、同分母：只加分子

先看最简单的两个分数：

$$\frac{1}{8} + \frac{3}{8}$$

两个分数的**分母已经相同**，都是 8。这时只需要把分子加起来，分母**原封不动**照抄：

$$\frac{1}{8} + \frac{3}{8} = \frac{1+3}{8} = \frac{4}{8}$$

### 1.1 为什么分母不变

把 $\dfrac{1}{8}$ 想成一块披萨的一角——整张披萨切成 8 块，取其中 1 块。$\dfrac{3}{8}$ 就是 3 块。

- 1 块 + 3 块 = 4 块
- 4 块仍然是"切成 8 份之后"的 4 块，所以还是写 $\dfrac{4}{8}$

这和"1 个苹果 + 3 个苹果 = 4 个苹果"是同一套逻辑：**被数的东西是"八分之一"这个单位**，单位没变，变的只是有几个。

> **分母表示每一份有多大（magnitude），分子表示有几份。** 加减只是在数"几份"，不会改变"一份有多大"，所以分母不动。

### 1.2 千万别把分母也加起来

一个常见的错误是把上下都相加：

$$\frac{1}{8} + \frac{3}{8} \;\neq\; \frac{1+3}{8+8} = \frac{4}{16} = \frac{1}{4}$$

!!! warning "错在哪里"

    右边把披萨切成了 16 份，可我们手里明明只有 8 份大小的 4 块。$\dfrac{1}{4}$ 表示四分之一张披萨，而实际是**一半**——差了一倍。

    记住：**加减法只动分子，分母是"单位"，单位不变。**

### 1.3 算完要看能不能化简

$$\frac{4}{8} = \frac{1}{2}$$

4 块八分之一，正好是半张披萨，所以答案化简成 $\dfrac{1}{2}$。**先算，再化简**——化简只是换个写法，不影响结果。

## 二、异分母：先通分

分母不同时，不能直接加分子——$\dfrac{1}{3}$ 和 $\dfrac{1}{4}$ 的"一份"大小不一样，三份之一和四份之一没法直接数。

办法是**把它们改写成同分母的分数**，用的正是 [16. 最小公倍数](16-最小公倍数.md) 里的方法。

**例 1**：$\dfrac{1}{3} + \dfrac{1}{4}$

### 第一步：找分母的最小公倍数

3 和 4 的最小公倍数是 12。这个 12 就是新的公共分母。

### 第二步：两个分数各自扩成 12 分之几

分数的大小不能变，所以**分子分母必须同乘同一个数**（相当于乘以 1）：

$$
\begin{aligned}
\frac{1}{3} &= \frac{1 \times 4}{3 \times 4} = \frac{4}{12} \quad(\text{分母 } 3 \times 4 = 12，\text{分子也乘 } 4)\\[4pt]
\frac{1}{4} &= \frac{1 \times 3}{4 \times 3} = \frac{3}{12} \quad(\text{分母 } 4 \times 3 = 12，\text{分子也乘 } 3)
\end{aligned}
$$

**乘几是怎么定的？** 用目标分母除以原分母：

$$12 \div 3 = 4,\qquad 12 \div 4 = 3$$

### 第三步：同分母相加

$$\frac{1}{3} + \frac{1}{4} = \frac{4}{12} + \frac{3}{12} = \frac{7}{12}$$

7 和 12 没有公共因数，$\dfrac{7}{12}$ 已经是最简形式，这就是最终答案。

## 三、减法同理

异分母相减走完全一样的流程，只是最后一步把加换成减。

**例 2**：$\dfrac{1}{3} - \dfrac{1}{4}$

沿用上面的通分结果：

$$\frac{1}{3} - \frac{1}{4} = \frac{4}{12} - \frac{3}{12} = \frac{4 - 3}{12} = \frac{1}{12}$$

同分母的减法更直接：**分母不动，分子相减**。

$$\frac{5}{7} - \frac{2}{7} = \frac{5-2}{7} = \frac{3}{7}$$

## 四、再看两个例子

### 4.1 分母互质：最小公倍数就是乘积

**例 3**：$\dfrac{1}{5} + \dfrac{2}{11}$

5 和 11 没有公共因数，最小公倍数是 $5 \times 11 = 55$。两个分数各自扩到 55 分之几：

$$
\begin{aligned}
\frac{1}{5} &= \frac{1 \times 11}{5 \times 11} = \frac{11}{55}\\[4pt]
\frac{2}{11} &= \frac{2 \times 5}{11 \times 5} = \frac{10}{55}
\end{aligned}
$$

$$\frac{1}{5} + \frac{2}{11} = \frac{11}{55} + \frac{10}{55} = \frac{21}{55}$$

21 和 55 没有公共因数（$21 = 3 \times 7$，$55 = 5 \times 11$），不能再化简。

### 4.2 结果是负数也没关系

**例 4**：$\dfrac{2}{7} - \dfrac{3}{5}$

最小公倍数是 35：

$$
\frac{2}{7} = \frac{10}{35},\qquad \frac{3}{5} = \frac{21}{35}
$$

$$\frac{2}{7} - \frac{3}{5} = \frac{10}{35} - \frac{21}{35} = \frac{10 - 21}{35} = -\frac{11}{35}$$

被减数比减数小，结果是负的——负号写在分母前面（或分子上），写法是

$$-\frac{11}{35} = \frac{-11}{35}$$

!!! note "负号放在哪里都一样"

    $-\dfrac{11}{35}$ 和 $\dfrac{-11}{35}$ 是同一个数，只是符号的位置不同。习惯上把负号写在**分数线的正前方**，读作"负的 35 分之 11"。

## 五、完整步骤

异分母加减，固定走这四步：

| 步骤 | 做什么 | 例：$\dfrac{1}{3} + \dfrac{1}{4}$ |
| --- | --- | --- |
| 1 | 求分母的最小公倍数 | 3 和 4 的最小公倍数 = 12 |
| 2 | 两个分数各自通分（分子分母同乘） | $\dfrac{1}{3} \to \dfrac{4}{12}$，$\dfrac{1}{4} \to \dfrac{3}{12}$ |
| 3 | 分子加或减，分母照抄 | $\dfrac{4 + 3}{12} = \dfrac{7}{12}$ |
| 4 | 能化简就化简 | 7 和 12 无公因数，已是答案 |

!!! tip "补充（视频未讲）：分母不互质时，为什么必须用最小公倍数？"

    通分其实不一定要用**最小**公倍数——用乘积也行。比如 $\dfrac{1}{6} + \dfrac{1}{9}$：

    $$\frac{1}{6} + \frac{1}{9} = \frac{9}{54} + \frac{6}{54} = \frac{15}{54} = \frac{5}{18}$$

    用 54 也算对了，但算完还得再化简一次。而 6 和 9 的最小公倍数是 18，直接通分到 18：

    $$\frac{1}{6} + \frac{1}{9} = \frac{3}{18} + \frac{2}{18} = \frac{5}{18}$$

    一步到位。**用最小公倍数 = 让数字尽量小、省掉最后那步化简**，这正是 [16. 最小公倍数](16-最小公倍数.md) 最直接的用处。

## 六、核心总结

```
        同分母 ──→ 分子加/减，分母照抄 ──→ 化简
           │
        异分母
           │
      求分母的最小公倍数（通分）
           │
   分子分母同乘同一个数（值不变）
           │
        分子加/减 ──→ 化简
```

| 知识点 | 说明 |
| --- | --- |
| 同分母加减 | 分母不动，只算分子 |
| 分母不变的原因 | 分母是"单位"，加减只是在数几份 |
| 最大误区 | 分子分母一起加，等于把单位也改了 |
| 异分母加减 | 先通分到最小公倍数，再按同分母算 |
| 通分的合法性 | 分子分母同乘同一个数 = 乘以 1 |
| 最后一步 | 能化简就化简；负号写在分数线前 |

> **一句话总结**：分母相同就直接加减分子、分母照抄；分母不同就先通分到最小公倍数，把"每一份的大小"统一之后再数分子。
